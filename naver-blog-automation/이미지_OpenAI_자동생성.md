# 블로그 이미지 자동 생성 (OpenAI 공식 Image API)

이미지는 ChatGPT 웹사이트를 사람처럼 클릭해서 만들지 않습니다.
프로그램이 **OpenAI 공식 API 주소로 직접 요청**해서 그림 파일을 받아 옵니다.

## 역할 나누기

| 누가 | 무엇을 |
|---|---|
| 이 프로그램 | 본문 분석 · 프롬프트 작성 · API 호출 · 파일 저장 · 경로 전달 |
| OpenAI Image API | 실제 그림 생성 |
| 네이버 블로그 자동화 | 저장된 JPEG 를 불러와 본문에 넣고 올리기 |

만들기와 올리기를 나눈 이유는, 글을 올릴 때마다 그림을 다시 만들면
돈과 시간이 낭비되고 그림도 매번 달라지기 때문입니다.

---

## 처음 한 번만 하는 준비

1. `.env.example` 을 복사해 이름을 **`.env`** 로 바꿉니다.
2. 아래 두 줄을 채웁니다.

   ```
   OPENAI_API_KEY=여기에_키를_붙여넣기
   OPENAI_IMAGE_MODEL=gpt-image-1
   ```

   * 키는 <https://platform.openai.com/api-keys> 에서 만듭니다.
   * 모델 이름을 비워 두면 `config/image_style.json` 의 기본값을 씁니다.
   * `.env` 는 `.gitignore` 에 있어 깃허브에 올라가지 않습니다.
     **키를 다른 문서나 대화창에 적지 마세요.**

## 쓰는 법

```bash
npm run images:ai -- --post output/2026-W35/stock/2026-08-24
```

한 주 전체를 한 번에:

```bash
npm run images:ai -- --week output/2026-W35
```

| 옵션 | 뜻 |
|---|---|
| `--dry-run` | 프롬프트만 만들어 저장하고 API 는 부르지 않습니다. 돈이 들지 않습니다. |
| `--engine openai` | 공식 API 만 씁니다. 실패하면 실패로 보고합니다. **기본값** |
| `--engine auto` | API 가 안 되면 이 PC 에서 Pillow 로 그려서라도 파일을 만듭니다. |
| `--engine pillow` | API 를 쓰지 않고 이 PC 에서 그립니다. 인터넷·키가 없어도 됩니다. |

먼저 `--dry-run` 으로 프롬프트를 확인한 뒤 실제로 부르는 것을 권합니다.

## 이미지 문구를 직접 정하는 법 (권장)

자동 분석은 본문에서 문장을 뽑아 씁니다. 그런데 본문 문장은 보통 35~50자라
사양이 요구하는 **10~25자**로 줄이면 뜻이 깨집니다.

그래서 원고 앞머리(`---` 사이)에 이렇게 적으면 그 문구를 그대로 씁니다.

```yaml
infographic:
  kind: three              # compare | three | flow | metaphor | chart
  title: 월요일 아침에 볼 숫자 셋
  points:
    - 코스피와 코스닥 지수
    - 달러 대비 원화 환율
    - 지난주와 견주어 보기
  footer: 숫자보다 방향을 보세요
  slug: weekly_check       # 파일 이름에 쓸 영문 키워드
```

비교형은 `points` 대신 이렇게 씁니다.

```yaml
infographic:
  kind: compare
  title: 몰빵과 나누기의 차이
  left_label: 나누어 담기
  right_label: 한 곳에 몰기
  left_items:
    - 하나 떨어져도 남습니다
    - 밤에 잠이 옵니다
  right_items:
    - 한 번에 반토막 납니다
    - 손이 떨립니다
  footer: 대박이 아니라 지키기입니다
```

블록이 없으면 자동 초안으로 만들고, 화면에
`문구가 자동 초안입니다` 라고 알려 줍니다.

---

## 다섯 가지 유형

| 키 | 이름 | 언제 |
|---|---|---|
| `compare` | 비교형 | 두 가지를 견줄 때 |
| `three` | 3단 요약형 | 핵심 세 가지를 정리할 때 |
| `flow` | 흐름형 | 원인 → 결과 순서를 보일 때 |
| `metaphor` | 비유형 | 쉬운 사물에 빗댈 때 |
| `chart` | 차트 교육형 | 그래프 보는 법을 설명할 때 |

## 저장되는 곳

| 무엇 | 어디 |
|---|---|
| 받은 원본 | `storage/generated/raw/` |
| 최종 JPEG | `storage/generated/final/` |
| 보낸 프롬프트 | `storage/prompts/` |
| 메타데이터 | `storage/manifests/` |
| 바탕화면 사본 | `바탕화면\Chat Gpt 이미지\` |

파일 이름은 `날짜_주제.jpg` 입니다. 예: `20260824_weekly_check.jpg`
같은 이름이 있으면 `_01`, `_02` 를 붙입니다. **덮어쓰지 않습니다.**

> **저장 폴더 안내**
> 사양에 적힌 경로는 `C:\Users\admin\Desktop\Chat Gpt 이미지` 입니다.
> 이 PC 에는 `admin` 사용자가 없어서 지금 로그인한 사용자의 바탕화면에 저장하고,
> 실행할 때마다 그 사실을 화면에 알려 줍니다.
> `admin` 계정을 쓰는 PC 에서는 사양대로 저장됩니다.

## 블로그에 올릴 때

올리는 단계에서는 이미지를 **다시 만들지 않습니다.**

```python
from services import image_for_article

r = image_for_article(article_id="stock_2026-08-24")
r["status"]        # REUSED = 있던 파일을 씀 / READY = 새로 만듦
r["storage_path"]  # 본문에 넣을 파일 경로
```

저장소에 맞는 파일이 있으면 그대로 쓰고, 없을 때만 새로 만듭니다.

## 자주 나오는 문제

| 화면에 나오는 말 | 뜻과 해결 |
|---|---|
| `OPENAI_API_KEY 가 없습니다` | `.env` 를 만들고 키를 넣으세요. |
| `HTTP 401` | 키가 틀렸거나 만료됐습니다. 새 키를 발급하세요. |
| `HTTP 429` | 잠깐 사이에 너무 많이 불렀습니다. 자동으로 2번까지 다시 겁니다. |
| `HTTP 400 ... model` | 모델 이름이 틀렸습니다. `.env` 의 `OPENAI_IMAGE_MODEL` 을 확인하세요. |
| `사양의 저장 폴더 ... 없습니다` | 오류가 아닙니다. 이 PC 바탕화면에 저장했다는 안내입니다. |

오류 메시지에 키가 보이는 일은 없습니다. 자동으로 가립니다.

## 알아 두실 점

* **한글 글자는 확인이 필요합니다.**
  이미지 생성 AI 는 한글을 가끔 틀리게 그립니다.
  프롬프트에 "글자 하나 바꾸지 말고 그대로" 라고 적어 두었지만,
  받은 그림의 글자가 맞는지는 **눈으로 보고 확인하셔야 합니다.**
  글자가 틀렸으면 다시 실행하거나 `--engine pillow` 로 만드세요.
  Pillow 로 그린 것은 한글이 항상 정확합니다.

* **규격 맞추기.**
  OpenAI 는 4:5(1200×1500)를 직접 지원하지 않습니다.
  가장 가까운 세로 규격(1024×1536)으로 받아 가운데를 잘라 1200×1500 으로 맞춥니다.
  가장자리가 조금 잘릴 수 있습니다.

* **비용.** 이미지 한 장마다 요금이 붙습니다. `--dry-run` 은 돈이 들지 않습니다.
