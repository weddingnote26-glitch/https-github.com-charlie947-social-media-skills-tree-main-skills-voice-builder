# 예시 원고

시스템이 만들어 내는 결과물이 어떤 모습인지 보여 주는 **견본**입니다.
실제 발행 대상이 아니며, 어느 블로그에도 올라가지 않습니다.

| 폴더 | 채널 | 글 |
|---|---|---|
| `coin/` | 친절한 코인 설명서 | 코인 백서, 초보자는 어디부터 읽어야 할까요 |
| `stock/` | 오락 5070 경제공부소 | ROE란 무엇일까요, 쉽게 풀어 봅니다 |

각 폴더에 들어 있는 것:

| 파일 | 무엇인가 |
|---|---|
| `post.md` | 최종 원고 — 앞머리 메타데이터 + 본문 |
| `post.html` | 네이버에 붙여넣는 용도 (브라우저로 열고 Ctrl+A → Ctrl+C) |
| `sources.md` | 참고 자료와 사실 확인 기록 |
| `checklist.md` | 15가지 자동 검수 결과 |
| `발행카드.md` | 올리기 직전에 대조하는 확인표 |

> ⚠ **이 견본은 두 블로그의 실제 글 양식을 분석하기 전에 만든 것입니다.**
> 제목 길이, 문단 방식, 이미지 배치 같은 것은 실제 블로그와 다를 수 있습니다.
> 샘플 게시물을 주시면 그 양식에 맞춰 다시 만듭니다.
