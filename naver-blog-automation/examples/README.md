# 참고 자료

실제 발행 대상이 아닙니다. 어느 블로그에도 올라가지 않습니다.

## `stock-실제글-참고용/`

**오락 5070 경제공부소의 실제 발행 글**입니다. (2026-08-21 발행)
사용자가 양식 분석용으로 제공한 글이며, 이 시스템이 만든 글이 아닙니다.

이 글로 두 가지를 했습니다.

1. **글 양식 분석** → `config/style_stock.md`
   제목 길이 49자, 본문 1,383자, 평균 문장 35자, 소제목 4개,
   괄호 뜻풀이 17회, 이미지 3장, 해시태그 7개 등을 실측했습니다.

2. **검수기 검증** → 이 글이 15개 검사 항목을 통과하는지 확인했습니다.
   처음에는 **막혔고**, 원인은 글이 아니라 제 설정이었습니다.
   (투자 유의 문구를 실제와 다르게 넣어 두었습니다) 실제 글 기준으로 고쳤습니다.

### 들어 있는 것

| 파일 | 무엇인가 |
|---|---|
| `post.md` | 실제 글을 시스템 형식으로 옮긴 것 (문장은 고치지 않았습니다) |
| `checklist.md` | 15개 항목 검수 결과 — 전부 통과 |
| `publish/` | 이 글로 만들어 본 업로드 패키지 견본 |

`publish/` 안을 보시면 실제 업로드 때 무엇이 만들어지는지 알 수 있습니다.
특히 `upload_checklist.md` 의 **0단계(블로그 ID 7가지 확인)** 를 봐 주세요.
