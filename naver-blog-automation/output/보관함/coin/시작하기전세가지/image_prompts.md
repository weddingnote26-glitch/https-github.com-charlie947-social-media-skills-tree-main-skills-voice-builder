## 1. start-guide-01.png

- **종류**: 대표 이미지
- **삽입 위치**: 도입부 아래
- **대체 텍스트**: 여행 떠나기 전 짐을 싸는 모습에 코인 투자 준비를 비유한 그림
- **담을 내용**:
  - 왼쪽: 집에서 차분히 가방을 싸는 캐릭터 (여유로운 표정)
  - 오른쪽: 공항에서 급하게 물건을 사는 캐릭터 (당황한 표정)
  - 가운데 대비 문구: "미리 준비" vs "급하게"
- **AI 생성 프롬프트**:
  ```
  세로형 2단 대비 인포그래픽.
  위쪽: 집에서 여유롭게 짐을 싸는 캐릭터, 파랑 계열 배경.
  아래쪽: 공항에서 급히 물건을 사는 캐릭터, 주황 계열 배경.
  글자는 최소한으로, 크고 또렷하게.
  ```

## 2. start-guide-02.png

- **종류**: 설명 이미지 (표)
- **삽입 위치**: 세 번째 소제목 아래
