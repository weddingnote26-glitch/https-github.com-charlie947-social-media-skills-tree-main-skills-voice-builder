# 보관함 — 언제든 올릴 수 있는 글

날짜가 정해지지 않은 **완성된 원고**를 모아 두는 곳입니다.

## 왜 필요한가요

시황·뉴스 글은 미리 쓰지 않습니다. 그런데 아침에 사정이 생겨
시황을 못 쓰는 날이 있습니다. 그럴 때 **여기서 하나 꺼내 올리면**
발행이 끊기지 않습니다.

개념·마인드·위험관리 글은 언제 올려도 내용이 낡지 않습니다.
그래서 미리 써서 쌓아 둘 수 있습니다.

## 쓰는 법

1. 여기서 글 하나를 고릅니다
2. 그 폴더를 `output/<주차>/<채널>/<날짜>/` 로 **복사**합니다
3. `post.md` 의 앞머리에서 아래 셋을 그날 값으로 고칩니다
   - `publish_date`
   - `weekday`
   - `post_id`
4. 검수 → 승인 → 발행 준비를 평소대로 진행합니다

```
python scripts/review.py
python scripts/approve.py
python scripts/prepare_publish.py
```

> 한 번 쓴 글은 이 폴더에서 지우거나 `사용함/` 으로 옮겨 두세요.
> 같은 글을 두 번 올리면 검수에서 중복으로 걸립니다.
