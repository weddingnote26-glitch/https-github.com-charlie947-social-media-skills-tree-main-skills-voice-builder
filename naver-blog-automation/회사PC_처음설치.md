# 회사 PC 처음 설치

> 이 문서는 **naver-blog-automation** 프로그램 전용입니다.
> 깃허브 저장소 자체를 처음 받아오는 방법은 한 단계 위 폴더의
> `블로그작업\회사PC_처음설치.md` 를 먼저 보세요.

**처음 한 번만** 하시면 됩니다. 그다음부터는 바탕화면에서 두 번 클릭이 전부입니다.

---

## 한눈에 보기

| 단계 | 무엇을 | 걸리는 시간 |
|---|---|---|
| 1 | 파이썬이 있는지 확인 | 1분 |
| 2 | 프로그램 폴더 위치 확인 | 1분 |
| 3 | 바탕화면 바로가기 만들기 | 1분 |
| 4 | 첫 실행 (자동으로 설치됨) | 3~5분 |

---

## 1단계 — 파이썬 확인

**시작 버튼 → `powershell` 입력 → 열기** 한 뒤 아래를 붙여넣고 Enter.

```bash
python --version
```

| 나온 결과 | 할 일 |
|---|---|
| `Python 3.9` 이상 | 2단계로 넘어가세요 |
| 아무것도 안 나오거나 오류 | 아래에서 설치하세요 |

### 파이썬 설치가 필요하면

<https://www.python.org/downloads/> 에서 내려받아 실행합니다.

> ⚠ 설치 첫 화면에서 **"Add Python to PATH"** 체크박스를 꼭 켜 주세요.
> 이걸 놓치면 프로그램이 파이썬을 못 찾습니다.

설치가 끝나면 **PowerShell 창을 닫고 새로 여세요.**

> **Node.js 는 설치하지 않으셔도 됩니다.**
> 이 프로그램의 모든 핵심 기능은 파이썬으로 동작합니다.
> Node 는 나중에 브라우저 자동 등록(선택 기능)을 켤 때만 쓰입니다.

---

## 2단계 — 프로그램 폴더 위치 확인

프로그램은 아래 위치에 있어야 합니다.

```
내 문서\블로그작업\naver-blog-automation\
```

이 폴더 안에 `start-naver-blog-automation.bat` 파일이 보이면 맞습니다.

> ⚠ **구글 드라이브·원드라이브 안에 두지 마세요.**
> 작업 기록(`.git`)이 깨집니다. 프로그램이 자동으로 경고하고 멈춥니다.
> 문서·보고서는 클라우드에 두셔도 괜찮습니다.

---

## 3단계 — 바탕화면 바로가기 만들기

프로그램 폴더에서 **`바탕화면_바로가기_만들기.ps1`** 파일을 찾습니다.

**오른쪽 클릭 → "PowerShell에서 실행"**

바탕화면에 **`네이버 블로그 자동화 실행`** 이라는 초록색 아이콘이 생깁니다.

> 폴더를 다른 곳으로 옮기셨다면, 옮긴 폴더에서 이 파일을 **다시 한 번** 실행하세요.
> 바로가기가 새 위치를 가리키도록 자동으로 고쳐집니다.

---

## 4단계 — 첫 실행

바탕화면의 **`네이버 블로그 자동화 실행`** 을 두 번 클릭합니다.

처음에는 이런 순서로 진행됩니다.

1. `아직 설치가 안 된 PC입니다` 라는 안내가 나옵니다
2. 전용 파이썬 환경을 만들고 필요한 프로그램을 내려받습니다 (**3~5분**, 인터넷 필요)
3. `이 PC를 뭐라고 부를까요?` 라고 물어봅니다 → **`회사`** 라고 입력하고 Enter
4. 설치가 끝나면 곧바로 메뉴가 뜹니다

메뉴가 이렇게 나오면 성공입니다.

```
   네이버 블로그 주간 콘텐츠 제작 도우미
   ...
   번호를 고르세요:
```

**8번(종료)** 을 눌러 닫으시면 됩니다.

## 설치 후 남는 것

| 만들어진 것 | 위치 | 동기화 |
|---|---|---|
| 전용 파이썬 환경 | `.venv\` | ❌ (PC마다 따로) |
| 개인 설정 | `config\settings.yaml` | ❌ (PC마다 따로) |
| 실행 기록 | `logs\` | ❌ |
| 로그인 정보 보관함 | `private\` | ❌ **절대 올라가지 않습니다** |

위 네 가지는 일부러 깃허브에 올라가지 않게 막아 두었습니다.
로그인 정보가 밖으로 나가지 않게 하기 위해서입니다.
