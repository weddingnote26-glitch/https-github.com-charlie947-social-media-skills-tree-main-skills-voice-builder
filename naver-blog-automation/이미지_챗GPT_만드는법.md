# 이미지, 챗GPT로 만드는 법

원고를 쓰면 게시물 폴더에 **`image_prompts.md`** 가 함께 생깁니다.
그 안의 프롬프트를 챗GPT에 **그대로 붙여넣으면** 그림이 나옵니다.

---

## 순서

1. 게시물 폴더를 엽니다. 예: `output\2026-W35\stock\2026-08-24\`
2. `image_prompts.md` 를 엽니다.
3. **`붙여넣을 프롬프트`** 상자의 글을 통째로 복사합니다.
4. 챗GPT에 붙여넣고 보냅니다.
5. 나온 그림을 **오른쪽 클릭 → 이미지 저장**
6. 같은 폴더의 **`images\`** 안에 넣습니다.
7. 파일 이름을 `image_prompts.md` 에 적힌 이름으로 바꿉니다. (예: `weekly-check-01.png`)

이미지 3장이면 3번을 세 번 반복하시면 됩니다.

---

## 가장 자주 겪는 문제: 한글이 깨집니다

챗GPT는 그림 안의 **한글을 자주 틀리게 씁니다.** 글자가 뭉개지거나, 없는 글자를 만들거나,
글자끼리 겹칩니다. 실제 블로그 이미지에서도 이런 일이 한 번 있었습니다.

### 그래서 이렇게 만듭니다

| 규칙 | 이유 |
|---|---|
| 그림 안 글자는 **짧은 낱말만** (2~6자) | 문장이 길수록 더 많이 깨집니다 |
| 넣을 글자를 **따옴표로 정확히 지정** | 챗GPT가 알아서 지어내지 않게 |
| 글자 수를 **다섯 덩어리 이하**로 | 많을수록 겹칩니다 |
| 만든 뒤 **반드시 눈으로 확인** | 자동으로는 못 잡습니다 |

### 글자가 깨졌을 때

같은 대화창에서 이렇게 말하면 됩니다.

```
글자가 깨졌습니다. 그림 안의 글자를 정확히 아래처럼만 넣어 다시 만들어 주세요.
"코스피"  "코스닥"  "환율"
글자는 크게, 서로 겹치지 않게 넉넉히 띄워 주세요.
```

두세 번 해도 계속 깨지면 **글자 없이 그림만 만들어 달라고 하고**,
글자는 나중에 직접 얹으시는 편이 빠릅니다.

## 채널마다 그림 분위기가 다릅니다

### 친절한 코인 설명서

```
세로형 3:4 · 검정 배경 · 형광 파랑/주황/초록 · 대비 강하게
상단 큰 제목 → 번호 매긴 단계(①②③) → 하단 슬로건
얼굴 달린 비트코인 같은 의인화 캐릭터
본문의 비유를 그대로 그림으로 (피자 비유 → 피자 그림)
```

### 오락 5070 경제공부소

```
가로형 4:3 · 흰 배경 · 초록(#2F855A)과 노랑(#D69E2E)
글씨 크게, 요소 적게, 여백 넉넉히
50~70대가 휴대폰으로 봐도 읽히도록
```

이 내용은 각 프롬프트 안에 이미 들어 있습니다. 따로 적으실 필요 없습니다.

## 넣으면 안 되는 것

- **실제 회사 이름·종목명** — 가게 A, 가게 B 로 씁니다
- **로고·상표** — 네이버, 삼성, 업비트 같은 것
- **뉴스 사진·남의 차트** — 직접 만든 그림만 씁니다
- **시세·가격·퍼센트 숫자** — 매일 바뀌어 그림이 금방 낡습니다
  (`①②③` 같은 **순서 번호는 넣으셔도 됩니다.** 금지 대상이 아닙니다)
  숫자가 꼭 필요한 표·차트는 `make_images.py` 로 만드는 편이 낫습니다

---

## 숫자가 들어가는 표는 챗GPT로 만들지 마세요

`image_prompts.md` 에 **만드는 방법: 표 (make_images.py)** 라고 적힌 것은
챗GPT 대신 아래 명령으로 만듭니다.

```bash
python scripts/make_images.py
```

이 방법은 `sources.md` 에서 교차확인된 숫자만 씁니다.
챗GPT는 숫자를 그럴듯하게 지어내므로 시세·지수에는 쓰지 않습니다.

## 다 만든 뒤

게시물 폴더의 `images\` 에 파일을 다 넣으셨으면 검수를 다시 돌립니다.

```bash
python scripts/review.py
```

`이미지 누락` 경고가 사라지면 됩니다.
