# 회사 PC 실행 방법

> 이 문서는 **naver-blog-automation** 프로그램 전용입니다.
> 처음 설치는 `회사PC_처음설치.md` 를 먼저 보세요.

---

## 평소에는 이것만 하시면 됩니다

### 바탕화면에서 두 번 클릭

```
바탕화면 → "네이버 블로그 자동화 실행"  (초록색 아이콘)
```

두 번 클릭하면 검은 창이 열리고, 아래 순서로 진행됩니다.

```
  [1/4] 프로그램 폴더를 확인합니다 …
  [2/4] 실행 환경을 확인합니다 …
  [3/4] 설정을 확인합니다 …
  [4/4] 프로그램을 시작합니다 …
```

그다음 메뉴가 뜹니다. **번호만 고르시면 됩니다.**

> PowerShell 명령어를 아실 필요가 없습니다. 창을 열고 번호를 누르는 게 전부입니다.

---

## 메뉴 보는 법

| 번호 | 무엇을 하나요 | 언제 |
|---|---|---|
| **0** | 내 블로그 글 가져오기 | 맨 처음 한 번 (양식 분석용) |
| **9** | 오늘 시세 확인 | 시황 글 쓰기 전에 |
| **1** | 다음 주 콘텐츠 12편 생성 | 주 1회 |
| **2** | 특정 게시물 다시 생성 | 마음에 안 드는 글이 있을 때 |
| **3** | 전체 원고 검수 | 생성 후 |
| **4** | 네이버 예약 발행 준비 | 검수 통과 후 |
| **5** | 승인된 글 예약 등록 | 발행 직전 |
| **6** | 발행 결과 확인 | 발행 후 |
| **7** | 설정 변경 | 발행 시각 등을 바꿀 때 |
| **8** | 종료 | 다 쓰셨을 때 |

**보통의 한 주 흐름:** `1` → `3` → `4` → `5` → `6`

## 다른 실행 방법 (바로가기가 없을 때)

프로그램 폴더에서 아래 파일을 **두 번 클릭**하셔도 똑같이 실행됩니다.

```
start-naver-blog-automation.bat
```

또는 `.ps1` 파일을 **오른쪽 클릭 → "PowerShell에서 실행"** 하셔도 됩니다.

```
start-naver-blog-automation.ps1
```

---

## 집 PC에서 한 작업 받아오기

**작업을 시작하기 전에 항상 먼저 하세요.**

한 단계 위 폴더(`내 문서\블로그작업`)의 **`받아오기.ps1`** 을
오른쪽 클릭 → "PowerShell에서 실행".

## 회사에서 한 작업 올리기

같은 폴더의 **`올리기.ps1`** 을 오른쪽 클릭 → "PowerShell에서 실행".

> 순서를 지켜 주세요. **받아오기 → 작업 → 올리기.**
> 이 순서를 지키면 두 PC의 작업이 섞이지 않습니다.

## 설정해야 하는 값

### 꼭 해야 하는 것 — 없습니다

첫 실행 때 `config\settings.yaml` 이 자동으로 만들어집니다.
기본값 그대로 쓰셔도 됩니다.

### 바꾸고 싶으면 — 메뉴 7번

| 항목 | 기본값 | 설명 |
|---|---|---|
| `machine_name` | 첫 실행 때 입력한 이름 | 집/회사 구분 (작업 충돌 경고에 씀) |
| `publish_times.coin` | `08:30` | 코인 채널 예약 발행 시각 |
| `publish_times.stock` | `07:30` | 주식 채널 예약 발행 시각 |
| `review.min_chars` | `1200` | 본문 최소 글자 수 |
| `browser.enabled` | `false` | 브라우저 자동 등록 (기본 꺼짐) |

## 민감정보 보관 주의사항

> **네이버 아이디·비밀번호를 파일에 적지 마세요.**
> 이 프로그램은 어디에도 비밀번호를 저장하지 않습니다.

| 종류 | 어디에 두나요 | 깃허브에 올라가나요 |
|---|---|---|
| 네이버 로그인 | 브라우저 창에서 **직접 로그인** | ❌ 절대 안 올라감 |
| 로그인 유지 정보(쿠키) | `private\browser-profile\` | ❌ 차단되어 있음 |
| 개인 설정 | `config\settings.yaml` | ❌ 차단되어 있음 |
| 실행 기록 | `logs\` | ❌ 차단되어 있음 |

### Claude API 키가 필요한 경우 (선택)

기본 설정(`generation.mode: claude_code`)에서는 **API 키가 필요 없습니다.**

`api` 모드로 바꿔 쓰실 때만 필요하며, 그때는 **파일이 아니라 윈도우 환경변수**로 넣습니다.
(이 프로그램은 `.env` 파일을 읽지 않습니다.)

PowerShell 창에서 한 번만:

```bash
setx ANTHROPIC_API_KEY "여기에-키-붙여넣기"
```

입력 후 **PowerShell 창을 닫고 새로 여세요.**

> ⚠ 키를 `settings.yaml` 이나 다른 파일에 절대 적지 마세요. 깃허브에 올라갑니다.

## 실행 기록은 어디에 남나요

```
naver-blog-automation\logs\
```

| 파일 이름 | 내용 |
|---|---|
| `실행기록_2026-08-24_083012.log` | 실행할 때마다 화면에 나온 내용 전부 |
| `2026-08.log` | 프로그램이 남기는 월별 작업 기록 |

`실행기록_*.log` 는 30일이 지나면 자동으로 지워집니다.
오류가 났을 때는 이 파일을 열어 보시면 원인이 그대로 적혀 있습니다.
