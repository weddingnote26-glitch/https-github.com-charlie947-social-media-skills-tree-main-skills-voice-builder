# 정리 그림(인포그래픽) 만드는 법

블로그 글 하나의 핵심을 **세로 그림 한 장**으로 만들어 주는 기능입니다.
챗GPT 없이 이 프로그램이 직접 그립니다. 한글이 깨지지 않습니다.

- 크기: 1200 x 1500 (세로 4:5)
- 형식: JPEG, 품질 95
- 저장 위치: `바탕화면\블로그 이미지`
- 파일 이름: `날짜_주제.jpg` (예: `20260824_weekly_check.jpg`)
  같은 이름이 있으면 `_01`, `_02` 가 뒤에 붙습니다.

가장 중요한 원칙은 **한 그림 = 한 메시지** 입니다.
본문을 그대로 옮기지 않고, 읽는 분이 3초 안에 알아볼 한 가지만 담습니다.

---

## 1. 프로그램에서 만들기 (가장 쉬움)

1. 바탕화면의 `네이버 블로그 도우미` 를 두 번 누릅니다.
2. 왼쪽 메뉴에서 **이미지 관리** 를 누릅니다.
3. 위 목록에서 그림을 만들 글을 한 줄 고릅니다.
4. **정리 그림 만들기** 를 누릅니다.
5. 끝나면 **만든 그림 폴더 열기** 를 눌러 확인합니다.

## 2. 명령으로 만들기

```bash
npm run image -- --post output/2026-W35/stock/2026-08-24
```

다섯 가지 유형이 어떻게 생겼는지 한 번에 보고 싶을 때:

```bash
npm run image:demo
```

---

## 3. 그림에 들어갈 문구 정하기

문구는 **원고가 직접 정합니다.** `post.md` 맨 위 `---` 사이에
아래처럼 `infographic:` 칸을 적어 두면 그대로 그려집니다.

```yaml
infographic:
  kind: three
  slug: weekly_check
  title: 월요일 아침에 볼 숫자 셋
  points:
    - 코스피와 코스닥 지수
    - 달러 대비 원화 환율
    - 지난주와 견주어 보기
  footer: 숫자보다 방향을 보세요
```

### 왜 직접 적어야 하나요

본문 문장은 보통 35~50자입니다. 그림에 들어갈 문구는 10~25자여야 읽힙니다.
프로그램이 기계적으로 줄이면 `다르게 움직` 처럼 낱말이 깨집니다.
그래서 **최종 문구는 사람이 정하고, 자동 분석은 초안으로만** 씁니다.

`infographic:` 칸이 없으면 프로그램이 본문에서 알아서 뽑아 초안을 만듭니다.
그때는 실행 결과에 `문구 출처 : 자동 초안` 이라고 나옵니다.
**자동 초안은 그대로 쓰지 마시고 눈으로 확인한 뒤 위 칸에 옮겨 적어 주세요.**

### 적을 수 있는 값

| 이름 | 뜻 | 규칙 |
|---|---|---|
| `kind` | 그림 유형 | 아래 다섯 가지 중 하나 |
| `title` | 큰 제목 | 12~24자, 두 줄까지 |
| `points` | 핵심 항목 | 2~4개, 각 10~25자 |
| `footer` | 아래 한 줄 | 50자 이내 |
| `slug` | 파일 이름에 쓸 말 | 영문 소문자와 밑줄 |
| `left_label` / `right_label` | 비교형 좌우 제목 | 비교형에만 |
| `left_items` / `right_items` | 비교형 좌우 항목 | 비교형에만, 각 2~4개 |

### 다섯 가지 유형

| `kind` | 이름 | 이럴 때 씁니다 |
|---|---|---|
| `three` | 3단 요약형 | 핵심 3가지를 번호로 보여 줄 때 (가장 많이 씁니다) |
| `compare` | 비교형 | A와 B의 차이를 보여 줄 때 |
| `flow` | 흐름형 | 원인에서 결과로 이어지는 순서를 보여 줄 때 |
| `metaphor` | 비유형 | 어려운 개념을 익숙한 것에 빗댈 때 |
| `chart` | 차트 교육형 | 차트나 지표 보는 법을 알려 줄 때 |

## 4. 그림에 넣지 않는 것

- 실제 종목 이름
- 실제 시세, 수익률, 퍼센트 같은 숫자
  (읽는 분이 투자 권유로 오해할 수 있습니다)
- 본문 문장을 그대로 옮긴 긴 글
- 이모지와 화살표 같은 그림 글자 (자동으로 지워집니다)

## 5. 색과 글자

바꾸지 마세요. 채널이 달라도 같은 색을 씁니다.

| 쓰임 | 색 |
|---|---|
| 바탕 제목 띠 | 남색 `#0B2A55` |
| 강조 · 번호 | 진한 파랑 `#123F7A` |
| 좋음 · 늘어남 | 초록 |
| 주의 · 줄어듦 | 빨강 |
| 눈에 띄게 | 노랑 |

글꼴은 맑은 고딕입니다. 50~70대가 보시기 편하도록 제목과 숫자를 크게 잡았습니다.

---

## 6. 자동 검수

그림을 그린 뒤 프로그램이 스스로 확인합니다.

- 규격이 1200 x 1500 인가
- 맨 위·아래에 글이 닿지 않았는가
- 제목이 너무 길지 않은가
- 핵심 항목이 있고 4개를 넘지 않는가

걸리면 글자를 줄여서 최대 세 번까지 다시 그립니다.
그래도 남으면 실행 결과에 `검수에서 걸린 것` 으로 보여 드립니다.

## 7. 알아 두실 점

- 원래 지시서에 적힌 저장 폴더 `C:\Users\admin\Desktop\Chat Gpt 이미지` 는
  이 컴퓨터에 없습니다. 그래서 `바탕화면\블로그 이미지` 를 씁니다.
  바꾸시려면 `scripts/infographic.py` 의 `default_out_dir()` 를 고치거나
  `--out "원하는 폴더"` 를 붙여 실행하세요.
- 이 그림은 **정리용 도표**입니다.
  사진 느낌의 삽화는 여전히 챗GPT로 만드시고,
  만드는 방법은 `이미지_챗GPT_만드는법.md` 를 보세요.
