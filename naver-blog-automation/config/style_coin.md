## 이미지의 생김새

캡처 3장으로 확인했습니다. **매우 특징적입니다.**

| 항목 | 실측 |
|---|---|
| 형태 | **세로형 인포그래픽 포스터** (AI 생성으로 보임) |
| 구성 | 상단 큰 제목 → 번호 매긴 단계(①②③) → 하단 슬로건 |
| 색감 | 화려한 네온·그라데이션, 검정 배경에 밝은 색 |
| 캐릭터 | **얼굴 달린 비트코인**, 피자, 진공청소기 등 의인화 |
| 한글 텍스트 | 이미지 **안에 대량으로** 들어감 |
| 본문과의 관계 | 본문의 비유를 **그대로 시각화** (피자 → 피자 그림) |
| 대체텍스트(alt) | 비어 있음 |

예시:
- 지지·저항 → 농구공이 바닥에서 튀고 천장에 부딪히는 그림, 파랑/주황 2단 대비
- 알트 불장 → 피자를 다 먹고 배부른 비트코인, 알트코인으로 돈이 흘러가는 화살표
- 흡성대법 → 진공청소기로 시장 돈을 빨아들이는 비트코인

> ⚠ **주의할 점을 하나 발견했습니다.**
> 세 번째 이미지 하단의 한글 문장이 다른 요소와 겹쳐 읽기 어렵게 렌더링돼 있었습니다.
> AI로 한글 텍스트가 많은 이미지를 만들 때 흔히 생기는 문제입니다.
> 만든 뒤 **글자가 겹치거나 깨지지 않았는지 눈으로 확인**하시는 편이 좋습니다.

## 확정된 사항 (2026-08-22 사용자 확인)

### 1. 발행 시각 — **월~토 08:30**

실제 발행 습관은 **08:30~09:00** 이라고 확인받았습니다.
예약 발행은 한 시각을 정해야 하므로 그 구간의 이른 쪽인 **08:30** 으로 설정했습니다.

| 채널 | 발행 요일 | 예약 시각 |
|---|---|---|
| 친절한 코인 설명서 | 월~토 | **08:30** |
| 오락 5070 경제공부소 | 월~토 | 07:30 |

두 채널을 1시간 띄워 두었습니다. 09:00 으로 바꾸시려면
`config/settings.yaml` 의 `publish_times.coin` 한 줄만 고치면 됩니다.

### 2. 매매팁 글의 투자 유의 문구 — **넣습니다**

템플릿 B(매매팁·투자마인드)에는 실제 글에 유의 문구가 없었지만,
매수 타이밍을 다루는 글이므로 **템플릿 A와 같은 문구를 넣기로** 확정했습니다.

```
(※ 본 포스팅은 투자를 권유하는 글이 아니며, 모든 투자의 책임은 본인에게 있습니다.)
```

검수기가 두 템플릿 모두에서 이 문구를 확인합니다. 없으면 발행이 막힙니다.

## 아직 모르는 것

- **금요일(위험관리) 슬롯**의 양식 — 템플릿 B를 쓸 것으로 보이나 확인 못 함
- 매매팁 글의 표본이 **1편뿐** — 소제목 개수(3개)가 고정인지 미확정
- 카테고리 전체 목록 (`코인시황뉴스`, `코인투자마인드` 외에 무엇이 있는지)
- 제목 말머리의 다른 종류 (`[친절한코인설명서]`, `[코린이 매매팁]`, `[코린이 멘탈케어]` 외)

> 관련 글 묶음에서 `[코린이 멘탈케어]` 라는 말머리를 하나 더 발견했습니다.
> 멘탈케어 글 1~2편을 주시면 세 번째 템플릿인지 B와 같은지 확인하겠습니다.
