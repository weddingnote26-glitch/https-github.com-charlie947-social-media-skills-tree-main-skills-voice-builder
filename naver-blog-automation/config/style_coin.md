## 이미지

캡처 3장으로 확인했습니다. **매우 특징적입니다.**

| 항목 | 실측 |
|---|---|
| 형태 | **세로형 인포그래픽 포스터** (AI 생성으로 보임) |
| 구성 | 상단 큰 제목 → 번호 매긴 단계(①②③) → 하단 슬로건 |
| 색감 | 화려한 네온·그라데이션, 검정 배경에 밝은 색 |
| 캐릭터 | **얼굴 달린 비트코인**, 피자, 진공청소기 등 의인화 |
| 한글 텍스트 | 이미지 **안에 대량으로** 들어감 |
| 본문과의 관계 | 본문의 비유를 **그대로 시각화** (피자 → 피자 그림) |

예시:
- 지지·저항 → 농구공이 바닥에서 튀고 천장에 부딪히는 그림, 파랑/주황 2단 대비
- 알트 불장 → 피자를 다 먹고 배부른 비트코인, 알트코인으로 돈이 흘러가는 화살표
- 흡성대법 → 진공청소기로 시장 돈을 빨아들이는 비트코인

> ⚠ **주의할 점을 하나 발견했습니다.**
> 세 번째 이미지 하단의 한글 문장이 다른 요소와 겹쳐 읽기 어렵게 렌더링돼 있었습니다.
> AI로 한글 텍스트가 많은 이미지를 만들 때 흔히 생기는 문제입니다.
> 만든 뒤 **글자가 겹치거나 깨지지 않았는지 눈으로 확인**하시는 편이 좋습니다.
