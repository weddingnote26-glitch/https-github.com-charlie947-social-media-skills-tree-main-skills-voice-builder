# 설치하고 쓰는 방법

**오락푸드 AI릴스 자동제작 스튜디오** — 회사 PC 설치 안내

---

## 1. 설치 파일 만들기 (한 번만, 준비하는 사람이)

프로그램 폴더에서 **`설치파일만들기.bat` 더블클릭.**

15~30분 걸립니다. 끝나면 폴더가 저절로 열리고 그 안에 파일이 있습니다.

> 이 안에서 설치 파일 제작 도구(Electron, 100MB 남짓)를 한 번 내려받습니다.
> 회사 방화벽이 막으면 이 단계에서 멈추지만, **프로그램 자체는 `start.bat` 으로 계속 쓸 수 있습니다.**

```
오락푸드-AI릴스-자동제작-스튜디오-Setup-x64.exe
```

> Node.js 가 필요합니다. 없으면 https://nodejs.org 에서 **LTS** 를 먼저 설치하세요.

## 2. 설치하기 (쓰는 사람이)

1. 위 `...Setup-x64.exe` 를 **두 번 클릭**
2. **"Windows의 PC 보호"** 경고가 뜨면 → **추가 정보** → **실행**
   (코드 서명 인증서가 없어서 나오는 경고입니다. 아래 설명 참고)
3. 설치 폴더는 그대로 두고 **[설치]**
4. 끝나면 **바탕화면에 아이콘**이 생깁니다

> **관리자 권한이 필요 없습니다.** 내 계정에만 설치됩니다.

## 3. 실행하기

바탕화면의 **`오락푸드 AI릴스 자동제작 스튜디오`** 아이콘을 두 번 클릭.

창이 하나 열립니다. 검은 명령창도, 브라우저 주소창도 없습니다.
처음 켤 때는 10~20초 걸립니다.

## 4. 처음 한 번 — API 키 넣기

프로그램 안 **설정** 메뉴에서 세 곳에 키를 넣고 각각 **저장**합니다.

| 칸 | 받는 곳 |
|---|---|
| Claude API 키 | console.anthropic.com → API Keys |
| ElevenLabs API 키 | elevenlabs.io → 프로필 → API Keys |
| 이미지 API 키 | platform.openai.com → API keys |

각각 **[연결 테스트]** 로 `✅ 연결 성공` 을 확인하세요.
그다음 **목소리 고르기**에서 목소리를 정하고, 맨 위 **⚡ 실행 모드**를 **실제 모드**로 바꿉니다.

> 키는 **이 PC 안에 암호화되어** 저장됩니다. 설치 파일이나 인터넷에 올라가지 않습니다.

## 5. 내 파일이 저장되는 곳

| 무엇 | 어디에 |
|---|---|
| **완성된 영상** | `내 문서\오락푸드 AI릴스\완성영상` |
| 설정·맛집 DB·API 키 | `%APPDATA%\오락푸드 AI릴스 자동제작 스튜디오` |
| 기록(로그) | 위 폴더 안 `logs` |

프로그램 안에서 **[폴더 열기]** 를 누르면 완성 영상 폴더가 바로 열립니다.

## 6. 지우기

**설정 → 앱 → 오락푸드 AI릴스 자동제작 스튜디오 → 제거**
또는 시작 메뉴의 제거 항목.

> **만든 영상과 설정은 지워지지 않습니다.** 프로그램만 없어집니다.
> 완전히 정리하려면 위 5번의 두 폴더를 직접 지우세요.

## 7. 새 버전으로 올리기

새 설치 파일을 **그냥 그 위에 설치**하면 됩니다.
만든 영상·설정·API 키는 그대로 남습니다.

---

## 자주 겪는 문제

| 증상 | 해결 |
|---|---|
| "Windows의 PC 보호" 경고 | **추가 정보 → 실행**. 코드 서명 인증서가 없어서 나옵니다 |
| 창이 안 열리고 오류 상자가 뜸 | 상자에 적힌 기록 파일 위치를 확인해 보여 주세요 |
| 아이콘을 두 번 눌렀는데 창이 하나만 | 정상입니다. 이미 켜져 있으면 그 창을 앞으로 가져옵니다 |
| 영상이 안 만들어짐 | 설정에서 **[연결 테스트]** 3개를 확인하세요 |
| 백신이 막음 | 설치 폴더를 예외로 등록하거나 회사 IT 에 문의하세요 |

## 알아두실 것

- **코드 서명 인증서가 없습니다.** 그래서 설치할 때 Windows 경고가 뜹니다.
  인증서를 구입해 서명하면 경고가 사라집니다.
- **앱 아이콘은 임시입니다.** 최종 로고를 주시면 `electron/icon.png` 를 바꾸고
  다시 만들면 됩니다.
- 이 프로그램은 **인터넷 연결이 필요합니다** (AI 대본·이미지·음성 생성).
