# KNOWN_ISSUES — 아직 남은 것

## 1. 사용자가 준비해야 하는 것

| 무엇 | 왜 | 없으면 |
|---|---|---|
| **Claude API 키** | 대본·캡션 생성 | 대본을 못 만듭니다 |
| **ElevenLabs API 키** | AI 음성 | 음성을 못 만듭니다 |
| **이미지 API 키** (OpenAI/Gemini) | 장면 이미지 | 임시 배경으로 대체됩니다 |
| **최종 로고** | 앱 아이콘 | 임시 아이콘이 쓰입니다 |
| **코드 서명 인증서** | 설치 경고 제거 | 설치할 때 Windows 경고가 뜹니다 |

## 2. 현재 막혀 있는 것 (계정 문제 — 코드 문제 아님)

**ElevenLabs 무료 요금제**
Voice Library 목소리를 프로그램에서 쓸 수 없습니다 (오류 402).
→ 목소리 고르기에서 `기본 · 무료 요금제 가능` 표시된 것을 고르거나 Starter 이상으로.

**OpenAI 크레딧 부족**
이미지 생성이 429 로 막혀 장면이 임시 배경으로 채워집니다.
→ platform.openai.com → Billing 에서 크레딧 확인.

## 3. 미검증 항목

| 항목 | 왜 |
|---|---|
| Windows 설치 파일 실제 생성 | 작업 환경이 리눅스라 NSIS 빌드를 못 돌렸습니다 |
| 회사 PC 설치·바로가기·재부팅 | 다른 컴퓨터입니다 |
| Windows 배율 100/125/150% | 재현 불가 |
| 설치본에서 MP4 렌더 | 설치 후 확인 필요 |

자세한 내용은 `INSTALL_VERIFICATION.md` 를 보세요.

## 4. 알려진 제약

- **폴더는 한 단계까지** — Master Reference 폴더 안의 폴더는 만들 수 없습니다
- **삭제에 휴지통 없음** — 기본 오락이 이미지는 `npm run character` 로 복구 가능
- **오늘의 릴스에 메뉴·가격 직접 입력 칸 없음** — 그만큼 팩트체크가 약합니다
- **Instagram 연결 미완** — Professional 계정 + 토큰 + 공개 주소가 필요합니다
