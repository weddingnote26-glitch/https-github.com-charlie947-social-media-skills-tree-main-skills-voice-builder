## 4. 설치 파일 만들기가 막힐 수 있는 경우

`설치파일만들기.bat` 은 2단계에서 Electron(100MB 남짓)을 github.com 에서 받습니다.
회사 방화벽이 막으면 여기서 멈춥니다.

**그래도 프로그램은 못 쓰게 되지 않습니다.** `start.bat` 방식이 그대로 살아 있습니다.
Electron 은 평소 업데이트(`업데이트.bat`)에는 들어 있지 않으므로, 실패해도
받아오기·빌드·실행에는 영향이 없습니다.

## 5. 설치 파일 만들 때 "Cannot create symbolic link" 오류

electron-builder 는 코드 서명 도구(winCodeSign)를 받아서 푸는데,
그 안에 **macOS 용 심볼릭 링크**가 들어 있습니다.
Windows 에서 심볼릭 링크를 만들려면 관리자 권한이나 개발자 모드가 필요해서
일반 계정에서는 이렇게 실패합니다.

```
ERROR: Cannot create symbolic link : 클라이언트에 필요한 권한이 없습니다
       ...\darwin\10.12\lib\libcrypto.dylib
```

우리는 코드 서명을 하지 않으므로 **그 macOS 부분은 필요가 없습니다.**

`설치파일만들기.bat` 이 실패를 감지하면 `scripts/fix-builder-cache.mjs` 로
darwin 폴더를 빼고 다시 풀어 자동으로 재시도합니다.

그래도 안 되면 둘 중 하나:

1. **개발자 모드 켜기** (권장, 한 번만)
   설정 → 개인 정보 및 보안 → 개발자용 → 개발자 모드 **켬**
2. `설치파일만들기.bat` 을 **마우스 오른쪽 클릭 → 관리자 권한으로 실행**

> 설치 파일을 못 만들어도 프로그램은 `start.bat` 으로 계속 쓸 수 있습니다.

## 설치본 안의 .bat 을 누르면 `Cannot find module ...` (2026-08-25 해결)

**증상**

```
Error: Cannot find module
  'C:\Users\USER\AppData\Local\Programs\orak-food-reel-studio\resources\app\scripts\fix-ffmpeg.mjs'
```

**원인**

`설치파일만들기.bat` 이 설치본 안(`resources\app\`)까지 딸려 들어갔습니다.
그 안에는 `scripts/` 폴더가 없어서(일부러 안 담습니다) 누르는 순간 죽습니다.
`prepare-desktop.mjs` 의 제외 목록에 `start.bat` · `업데이트.bat` 만 있고
`설치파일만들기.bat` 이 빠져 있었습니다.

**고친 것 (세 겹)**

1. 제외 목록(SKIP)에 `설치파일만들기.bat` · `폴더열기.bat` 추가 — 아예 안 담깁니다
2. 금지 목록(FORBIDDEN)에도 추가 — 혹시 담기면 **설치본 만들기가 중단**됩니다
3. `설치파일만들기.bat` · `업데이트.bat` 맨 앞에 자리 확인 —
   소스 폴더가 아니면 한글로 안내하고 소스 폴더를 열어 줍니다

**이미 설치하신 분**

설치본 안의 `설치파일만들기.bat` 은 그대로 남아 있습니다. 누르지 마세요.
**소스 폴더**(`start.bat` 이 있는 곳)의 같은 이름 파일을 쓰시면 됩니다.
`폴더열기.bat` → `[4]` 번이 그 폴더를 열어 줍니다.
