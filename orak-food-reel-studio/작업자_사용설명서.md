# 🥟 오락푸드 릴스 스튜디오 — 작업자 사용설명서

> 처음 쓰는 분을 위한 안내서입니다. 순서대로 따라 하면 됩니다.
> 모르는 게 나오면 멈추고 사장님께 물어보세요. 망가뜨릴 수 있는 건 없으니 겁먹지 않아도 됩니다.

## 0. 이 프로그램이 하는 일

가게 이름만 넣으면 AI가 **인스타그램 릴스 영상**(세로 짧은 영상)을 만들어 줍니다.
대본 쓰기, 그림 만들기, 목소리 녹음, 자막 붙이기를 전부 프로그램이 합니다.
우리는 **내용이 맞는지 확인하고, 마음에 안 드는 부분을 고치는 일**을 합니다.

## 1. 설치하기 (처음 한 번만)

1. 사장님께 받은 파일을 찾습니다: `오락푸드-AI릴스-자동제작-스튜디오-Setup-x64.exe`
2. 두 번 클릭합니다
3. 파란 창으로 "Windows의 PC 보호" 경고가 뜨면 → **[추가 정보]** 클릭 → **[실행]** 클릭
   (우리가 직접 만든 프로그램이라 뜨는 경고입니다. 바이러스가 아닙니다)
4. 설치가 끝나면 바탕화면에 **오락푸드 AI릴스 자동제작 스튜디오** 아이콘이 생깁니다

## 2. 처음 켰을 때 한 번만 할 일

1. 바탕화면 아이콘을 두 번 클릭해서 프로그램을 켭니다
2. 왼쪽 메뉴 맨 아래 **⚙️ 설정**을 클릭합니다
3. 사장님께 받은 **열쇠(API 키)** 들을 해당 칸에 붙여넣고 저장합니다

> 🔑 **열쇠는 비밀번호와 같습니다.** 카톡으로 다른 사람에게 보내거나, 화면을 찍어 올리면 안 됩니다.
> 열쇠를 아직 못 받았어도 괜찮습니다 — "연습 모드"로 화면 구경과 연습은 할 수 있습니다.

## 3. 릴스 만들기 (기본 순서)

1. 왼쪽 메뉴 **✨ 오늘의 릴스** 클릭
2. 가게 이름을 넣습니다 (예: `신림동 오향만두집`)
3. 스타일은 **🥟 만두탐정 오락이**를 고릅니다
4. **[AI 자동제작 시작]** 클릭
5. 막대가 차오르는 걸 기다립니다 (몇 분 걸립니다 — 그동안 다른 일 해도 됩니다)
6. 끝나면 그 릴스를 클릭해서 엽니다

## 4. 내용 확인하고 고치기 (제일 중요한 일)

릴스를 열면 위에 탭이 3개 있습니다. 순서대로 봅니다.

**① 업체 정보 입력**
- 가격, 영업시간, 전화번호가 맞는지 **직접 확인**해서 적습니다 (네이버 지도, 전화 등으로)
- ⚠ **모르면 비워 둡니다. 절대 추측해서 적지 않습니다.** 틀린 가격이 영상에 나가면 큰일납니다
- "⚠ 팩트체크 확인 필요"가 떠 있으면 → 그 항목을 확인해서 적어야 발행이 됩니다

**② 장면 편집**
- 왼쪽에서 장면을 클릭 → 오른쪽에서 나레이션(읽는 말)과 자막을 고칩니다
- 어색한 문장, 이상한 말투를 자연스럽게 다듬습니다
- 고쳤으면 꼭 **[💾 저장하고 영상 제작하기]**를 누릅니다 (안 누르면 영상에 반영 안 됩니다)

**③ 미리보기 · 발행**
- 영상을 끝까지 한 번 봅니다. 소리도 들어 봅니다
- 이상하면 ②로 돌아가 고치고 다시 저장합니다

## 5. 클링(Kling) 영상 넣기 — 배경을 진짜 움직이는 영상으로

그림이 밋밋할 때, 장면 배경을 진짜 움직이는 영상으로 바꿀 수 있습니다.

1. **[② 장면 편집]**에서 바꾸고 싶은 장면을 클릭
2. 오른쪽 아래 **🎥 장면 영상 클립** 칸에서 **[📋 클링 프롬프트 복사]** 클릭
3. 인터넷에서 **klingai.com** 접속 (사장님이 알려준 계정으로 로그인)
4. 영상 만들기에 붙여넣기 → **세로(9:16)** 선택 → 만들기 → 완성되면 **다운로드**
5. 받은 파일을 **🎥 칸에 마우스로 끌어다 놓기** → 「🎬 클립 사용 중」이 뜨면 성공
6. **[💾 저장하고 영상 제작하기]** 클릭

> 💡 장면이 3초인데 클링 영상이 5초면 앞 3초만 쓰입니다. 영상을 다 쓰고 싶으면
> 넣기 전에 그 장면의 **길이(초)** 칸을 5로 바꾸세요.
> 💡 잘못 넣었으면 **[클립 빼기]**를 누르면 됩니다. 원래대로 돌아갑니다.

## 6. 발행 (사장님 지시에 따라)

- 사장님이 "발행까지 해 줘"라고 했을 때만: **[③ 미리보기 · 발행]**에서 **[📅 예약 발행]** 또는 **[🚀 지금 발행]**
- 발행 전에 **최종 확인창**이 뜹니다 — 내용을 읽고 [게시하기]를 눌러야 실제로 올라갑니다
- 발행 권한이 없으면: **[📁 영상 폴더 열기]**로 완성 영상(`reel.mp4`)을 찾아 사장님께 보내면 됩니다
  (본문과 해시태그는 [📋 본문 복사] / [📋 해시태그 복사] 버튼으로)

## 7. 문제가 생겼을 때

| 상황 | 이렇게 하세요 |
|---|---|
| 빨간 글씨/노란 글씨가 떴다 | 그 문구를 **그대로 복사하거나 화면을 찍어서** 사장님께 보냅니다 |
| 프로그램이 멈췄다/꺼졌다 | 껐다가 다시 켭니다. 만들던 건 저장되어 있습니다 |
| 만들다 실패했다고 나온다 | 그 릴스를 열어 [🔄 다시 만들기]를 눌러 봅니다 |
| 영상에 소리가 없다 | 화면의 안내문을 확인하고 사장님께 알립니다 |

**절대 하지 말 것 3가지**
1. 확인 안 된 가격·영업시간을 적어 넣기 ❌
2. API 키(열쇠)를 다른 사람에게 보내기 ❌
3. 발행 지시가 없는데 [지금 발행] 누르기 ❌
