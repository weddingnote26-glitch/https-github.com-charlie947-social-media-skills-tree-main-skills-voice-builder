## 2. ⚠ PC에서 남은 일 (여기부터 시작)

PC 폴더가 **합치다 멈춘 상태**입니다. 아래를 그대로 하면 됩니다.

### 2-1. 먼저 폴더로 이동 (이걸 안 하면 아래 git 명령이 전부 실패합니다)

PowerShell 을 열고 **아래 한 줄을 통째로** 붙여넣으세요. `cd` 와 따옴표까지 함께입니다.

```
cd "C:\Users\USER\Documents\블로그작업\orak-food-reel-studio"
```

⚠ 경로만 붙여넣으면 안 됩니다. PowerShell 이 그것을 "실행할 프로그램 이름" 으로 알아듣고
`CommandNotFoundException` 을 냅니다. 앞의 `cd ` 가 "그 폴더로 가라" 는 뜻입니다.

**확인**: 왼쪽 프롬프트가 이렇게 바뀌어야 합니다.

```
PS C:\Users\USER\Documents\블로그작업\orak-food-reel-studio>
```

아직 `PS C:\Users\USER>` 라면 이동이 안 된 것이니 여기서 멈추고 다시 하세요.
(`C:\Users\USER` 에는 git 저장소가 없어 어떤 git 명령도 듣지 않습니다)

### 2-2. 상태 확인
```
git status
```
`Unmerged paths` 가 보이면 예상대로입니다.

### 2-3. 내가 따로 고친 게 있는지
```
git diff --stat HEAD -- :/orak-food-reel-studio
```
아무것도 안 나오면 다음으로. 뭔가 나오면 그 내용을 Claude 에게 보여주고 멈추세요.

### 2-4. 릴스 폴더를 올라간 쪽으로 맞추고 합치기 마무리
```
git checkout origin/claude/orak-food-reel-studio-2kux9t -- :/orak-food-reel-studio
git add :/orak-food-reel-studio
git commit --no-edit
```
경로 앞의 `:/` 는 "저장소 맨 위 기준" 이라 어느 하위 폴더에서 쳐도 같습니다.

### 2-5. 업데이트 다시
같은 폴더의 `업데이트.bat` 더블클릭.
두 번째 단계에서 `WORKLOG.md` · 블로그 폴더 충돌이 날 수 있습니다 — 릴스 스튜디오와 무관하니
화면을 그대로 복사해 Claude 에게 보여주세요.

### 2-6. 확인
프로그램을 열어 왼쪽 위가 **"오락 숏폼 / 제작 스튜디오"**, 메뉴에 **🎞 외부 영상 AI 음성** 이 있으면 완료.
