## 2. 내일 PC에서 할 일 (순서대로)

### ① 최신 코드 받기
`업데이트.bat` 더블클릭 → `설치파일만들기.bat` → 설치 → 실행

> 사이드바 아래 **빌드 표시가 `34efc13`** 이면 최신입니다.
> 다른 값이면 아직 예전 코드입니다.

### ①-2 먼저 답해 주실 것 — 이미지 모델 이름

마지막에 **`gemini-3.6-flash`** 라고 주셨는데, 무슨 뜻인지 확인하지 못한 채 끝났습니다.

- 이미지 모델을 이 이름으로 바꾸시려는 것이라면, 설정 → 이미지 생성의
  **모델** 칸에 그대로 넣으시면 됩니다 (`.env` 의 `IMAGE_MODEL` 도 같은 역할).
- 지금 코드의 Gemini 기본값은 `gemini-2.5-flash-image` 입니다.
  빈 칸으로 두면 이 값이 쓰이고, 적어 넣으면 그 이름으로 호출합니다.
- **주의**: 이름이 실제로 존재하는 모델이어야 합니다. 이 작업 환경은 바깥 통신이
  막혀 있어 `gemini-3.6-flash` 가 실제 있는 모델인지 확인하지 못했습니다.
  Google AI Studio 에서 쓸 수 있는 모델 목록을 한 번 봐 주세요.

### ② 확인해 주셔야 하는 것 — **AI 배경 이미지**

이 작업 환경에는 이미지 API 키가 없어서, 배경은 **연습 모드(단색)로만** 확인했습니다.
캐릭터·한글 간판·영상 규격은 실제로 확인했지만, **배경이 한국 식당처럼 나오는지는
사장님 PC에서 실제 키로 확인이 필요합니다.**

1. ⚙️ 설정 → 실행 모드를 **🚀 실제 모드**로
2. 이미지 API 키 확인 (Gemini 또는 Cloudflare)
3. 릴스 하나를 **[다시 만들기]**
4. 배경에 **외국 간판·영어·깨진 글자가 없는지** 보기

기대와 다르면 **그 프레임을 캡처해서 주시면** 프롬프트를 더 조이겠습니다.

### ③ 게시하기 버튼 열기

지금 막고 있는 것은 두 가지입니다 (버튼 위에 이유가 표시됩니다).

- **발행 전 검수 5항목** → 릴스의 [🔎 완성 콘텐츠 미리보기·검수]에서 체크
- **영상 공개 주소** → 설정 → Instagram → [지금 이 프로그램 주소] 칸의
  터널 명령을 복사해 실행 → 나온 `https://….trycloudflare.com` 주소를 넣고 저장

두 개가 풀리면 [게시하기]가 켜집니다.
