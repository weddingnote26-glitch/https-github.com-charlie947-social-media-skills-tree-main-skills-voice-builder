## 고친 것

1. **영상 표시·서빙** — `mediaUrl` 이 표식 없는 경로는 `/api/media/abs?p=절대경로` 로 묻고,
   서버가 허용 폴더(output·assets·ROOT) 안인지 검사 후 서빙. `serveLocalFile` 은
   전달된 기준 폴더 각각을 기준으로 검사(설치형 출력 폴더 지원). `publicUrlFor` 는

설치형 앱은 켤 때마다 **빈 포트를 아무거나** 골라 열었다(`freePort()`).
Cloudflare Tunnel 은 `--url http://localhost:3000` 처럼 포트를 못 박아 두고 쓰기 때문에,
프로그램을 다시 켜면 터널이 빈 자리를 가리켜 **502** 가 나고 발행이 조용히 실패한다.
`start.bat`(3000 고정)으로 켰을 때와 바탕화면 아이콘으로 켰을 때 동작이 달랐다.

  밀렸을 때는 `fixed:false` 로 알려 주고, 앱 로그에도 밀린 포트를 남긴다.
- `src/lib/app-address.ts` (신규) — 브라우저 주소에서 "지금 어느 주소·포트로 열려 있나" 를 판단한다.

다른 장면에 `대표 메뉴 · 손만두 6,000원`, `이용 정보 · 영업시간 · 주차 · 확인일` 이
깨짐 없는 한글로 찍혔다. 첫 검증에서 판 3개가 한 프레임에 겹쳐 보여, 자리를 나누도록 고친 뒤 다시 확인했다.

## 검증이 잡아낸 것 (그냥 넘어갔으면 못 봤을 문제)

- 로그에는 "6/9 장면에 오락이 등장" 이라고 찍히는데 DB 에서 읽으면 **0/9** 이었다.
  → `character_presence` 칸이 없던 것을 여기서 발견했다.
- 간판·메뉴판·정보판이 **첫 프레임에 한꺼번에 겹쳐** 나왔다. → 자리를 나눠 고쳤다.
- 낱말이 안 맞으면 확인된 영업정보가 **그냥 버려졌다.** → 빈 장면에 올리도록 고쳤다.

## 하지 않은 것 (정직 보고)

- **OCR 외국어 검수는 넣지 않았습니다.** tesseract.js 는 한국어 인식 데이터를 실행 중에
  인터넷에서 내려받는 구조라, 사용자 PC 가 방화벽 뒤에 있으면 조용히 깨집니다.
  이 환경에서는 바깥 통신이 막혀 그 동작을 시험할 수도 없었습니다.
  대신 **애초에 AI 가 글자를 그리지 않게 하고** 글자는 프로그램이 쓰도록 막았습니다.
- **AI 배경 이미지 자체는 이 환경에서 만들어 보지 못했습니다.** 이미지 API 키가 없어
  Sample Mode(단색 배경)로 돌렸습니다. 한글 합성·캐릭터 배치·영상 규격은 실제로 확인했지만,
  "배경이 한국 식당처럼 나오는가" 는 **사용자 PC 에서 실제 키로 확인이 필요합니다.**
- 장면별 캐릭터 위치·크기 조절 UI 는 넣지 않았습니다 (현재는 대본의 corner/side/hero 로 정해집니다).
- 포터블 ZIP 은 이 프로젝트에 원래 없습니다 (설치형 .exe + start.bat).
