
## 4. 고친 김에 같이 잡은 것

| 증상 | 원인 | 조치 |
|---|---|---|
| `왕만두 6,000원` → 이름 `왕만두 6` / 가격 `000원` | 쉼표를 구분자로 먼저 봤다 | 가격을 뒤에서부터 최대로 잡도록 규칙 변경 (시험 추가) |
| 저장하면 화면 전체가 "불러오는 중…" 으로 돌아감 | 저장 후 `scenes` 를 `null` 로 되돌렸다 | 업체 정보 저장은 장면을 건드리지 않는다 |
| 설정의 기본 모델 이름이 칸에 잘림 | 자리표시자에 넣어서 폭에 잘렸다 | 도움말 줄로 내리고 상수에서 직접 읽음 |
| 고른 기준 이미지를 밖에서 지우면 참조 0장 | 목록이 비지 않아 기본값으로 안 돌아갔다 | 전부 사라지면 기본 Master Reference 로 복귀 |
