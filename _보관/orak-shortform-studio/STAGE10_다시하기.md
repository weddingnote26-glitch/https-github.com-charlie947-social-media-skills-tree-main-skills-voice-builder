## 1. 자료 폴더 이름 확정

```
내 문서 › 오락 숏폼 스튜디오 › Projects › 20260901_할머니손칼국수 › final › 완성.mp4
```

`%LOCALAPPDATA%` 를 쓰지 않은 이유는 하나입니다 — **숨김 폴더입니다.**
담당자는 만든 영상을 직접 열어 보고 손으로 인스타에 올려야 합니다.
숨김 폴더에 두면 그때마다 회사에 물어봐야 합니다.

**한글에 띄어쓰기가 들어갑니다.** 탐색기에서 찾기 쉬우라고 그렇게 했습니다.
경로에 공백이 있으면 프로그램이 깨지기 쉬운데, 바깥 도구(FFmpeg)를 부를 때
**인자를 늘 리스트로 넘겨서** 막아 뒀습니다 (§3). 시험으로도 확인합니다.

### 헷갈리기 쉬운 것 하나

바탕화면의 **`오락_숏폼스튜디오`** (밑줄) 는 여전히 **쓰기 금지**입니다.
새 폴더 **`오락 숏폼 스튜디오`** (띄어쓰기) 와 이름이 비슷해서, 잘못 걸리면
자기 자료 폴더에 아무것도 못 쓰게 됩니다. 시험이 양쪽을 다 확인합니다.

```
쓸 수 있음   내 문서\오락 숏폼 스튜디오\Projects\...
쓸 수 없음   바탕화면\오락_숏폼스튜디오\...
쓸 수 없음   바탕화면\오락_당근_콘텐츠\...        (A 프로그램)
쓸 수 없음   바탕화면\오락이 마스터 파일\...
```

### 예전 폴더가 있으면

전에 쓰던 `ORAK_SHORTFORM_STUDIO` 가 남아 있으면 설정 화면이
「예전 폴더가 남아 있습니다」 라고 알려주기만 합니다.
**옮기지도 지우지도 않습니다** — 담당자가 만든 영상이 들어 있을 수 있습니다 (§0-1 4번).
시험이 예전 폴더 안의 파일이 그대로 남아 있는지 확인합니다.

## 2. 다시 하기 — **아무거나 다시 부르지 않습니다**

```
다시 부름       429 · 5xx · 인터넷 끊김        (Retry.BACKOFF)
다시 안 부름    열쇠가 틀림                    (NEVER_AUTH)
다시 안 부름    보낸 값이 틀림                  (NEVER_PARAM)
다시 안 부름    담당자가 판단할 일               (MANUAL)
다시 안 부름    무슨 일인지 모르는 예외
```

열쇠가 틀린 것을 세 번 부르면 **세 번 다 틀립니다.** 시간만 버립니다.
무슨 일인지 모르는 예외를 다시 부르면 **돈이 드는 일을 영문도 모른 채 반복**합니다.

기다리는 시간은 늘려 갑니다. 상대가 「잠시 뒤에」 라고 했는데 곧바로
다시 부르면 더 오래 막힙니다.

```
2초 → 4초 → 8초 → 16초 → 32초 → 60초(상한)
```

**흩뜨립니다.** 다섯 장면이 동시에 막히면 5개가 정확히 같은 순간에
다시 부릅니다. ±25% 로 흩어서 다시 몰리지 않게 했습니다.

## 3. 껐다 켜도 이어서 — **다시 제출하지 않습니다**

이게 Stage 10 의 전부입니다.

영상 한 장면이 **약 483원**입니다. 맡겨 두고 프로그램이 꺼졌는데
다시 켰을 때 새로 제출하면 **이미 낸 483원을 또 냅니다.**

그래서 이렇게 합니다.

```
다시 켬
 → generation_jobs 에서 안 끝난 것을 찾음
 → 손잡이(external_task_id)로 **물어보기만** 함  ← 제출 아님
 → 다 됐으면 곧바로 내려받음
 → 아직이면 그대로 두고 다음에 또 물어봄
```

시험의 가짜 공급자는 **`submit()` 을 부르면 그 자리에서 시험을 깨뜨립니다.**
실수로 다시 제출하는 코드가 들어오면 6개 시험이 한꺼번에 빨개집니다.

### 한 번에 물어봅니다

조회는 동시처리 수를 쓰지 않습니다 (§2-1). 장면이 다섯이어도 **한 번**입니다.

### 30일이 지나면 포기합니다

Kling 결과는 **30일 뒤 지워집니다** (§2-1 · MVP 판정 20번).
그보다 오래된 것은 헛되이 부르지 않고 이렇게 알립니다.

```
할머니 손칼국수 · 장면 1 · 40일 전 — 결과가 지워졌습니다
→ 맡긴 지 30일이 지나 결과가 지워졌습니다. 그 장면은 다시 만들어야 합니다.
```

29일된 것은 아직 받아봅니다. 경계도 시험합니다.

### 실패하면 그대로 둡니다

내려받다 실패했을 때 「끝났다」 고 표시하면 **이미 낸 돈이 그대로 날아갑니다.**
그래서 실패하면 목록에 그대로 남겨 다음에 다시 누를 수 있게 합니다.

### 공급자가 아직 없어도 안 죽습니다

Kling 은 아직 안 붙였습니다. 그래도 「이어서 하기」 를 눌러 프로그램이
멈추면 안 됩니다. 「지금은 이어서 할 수 없습니다」 라고 말하고 목록은 그대로 둡니다.

**작업 목록** 화면 맨 위에 뜹니다.

```
┌ 지난번에 하던 일이 있습니다 ────────────────────────┐
│ 지난번에 맡겨 둔 영상 2개가 있습니다.                │
│ [이어서 하기] 를 누르면 결과를 받아옵니다.            │
│ 1개는 맡긴 지 30일이 지나 결과가 지워졌습니다.        │
│ 그 장면은 다시 만들어야 합니다.                      │

```

할 일이 없으면 아무것도 안 뜹니다.
표는 이제 **진짜 기록**을 보여줍니다 (기록이 없으면 예시라고 말합니다).
