# 깃허브 저장소를 비공개로 바꾸기

**읽는 사람**: 개발을 모르는 분
**걸리는 시간**: 3분
**해야 하는 이유**: 지금 이 저장소는 **누구나 볼 수 있습니다.**

---

## 0. 먼저 — 이게 무슨 얘기인가요

**깃허브(GitHub)** 는 프로그램 코드를 보관하는 창고입니다.
지금 사장님 창고는 **「공개」** 로 되어 있습니다. 주소만 알면
**모르는 사람도 안을 들여다볼 수 있다**는 뜻입니다.

지금 안에 든 것:

- 프로그램 코드
- 아직 안 올린 블로그 원고
- 만들다 만 콘텐츠 기획

**API 열쇠는 들어 있지 않습니다.** 그건 처음부터 창고에 안 넣게 만들어
두었으니 안심하셔도 됩니다. 하지만 **원고와 기획은 그대로 보입니다.**

그리고 **오락이 마스터 이미지 3장**은 아직 못 넣고 있습니다.
공개 창고에 넣으면 캐릭터 그림이 인터넷에 그대로 풀리기 때문입니다.
**비공개로 바꾸면 그때 넣을 수 있습니다.**

> **비공개로 바꿔도 사장님은 아무 불편이 없습니다.**
> 요금도 그대로 무료입니다. 달라지는 건 「남이 못 본다」 뿐입니다.

---

## 1. 하는 방법 (7단계)

### ① 깃허브에 들어갑니다

인터넷 창을 열고 주소창에 그대로 칩니다.

```
github.com
```

### ② 로그인합니다

오른쪽 위 **[Sign in]** 을 누르고 아이디·비밀번호를 넣습니다.

> 이미 로그인돼 있으면 오른쪽 위에 **동그란 사진**이 보입니다. 그러면 ③으로 갑니다.

### ③ 창고로 들어갑니다

주소창에 아래를 **그대로** 칩니다. (복사해서 붙여넣으셔도 됩니다)

```
github.com/weddingnote26-glitch/https-github.com-charlie947-social-media-skills-tree-main-skills-voice-builder
```

### ④ 위쪽 줄에서 [Settings] 를 찾습니다

창고 이름 아래에 회색 글씨가 한 줄 있습니다.

```
Code   Issues   Pull requests   Actions   ...   Settings
                                                 ↑ 이거
```

**맨 오른쪽 톱니바퀴 모양 [Settings]** 를 누릅니다.

> 안 보이면 창을 좌우로 넓혀 보세요. 화면이 좁으면 접혀 있습니다.

### ⑤ 맨 아래까지 내립니다

마우스 휠을 **끝까지** 내리면 **빨간 테두리 상자**가 나옵니다.

```
┌─ Danger Zone ────────────────────────────┐   ← 「위험 구역」 이라는 뜻입니다
│                                          │
│  Change repository visibility   [Change] │   ← 이 줄입니다
│                                          │
└──────────────────────────────────────────┘
```

빨갛다고 놀라지 마세요. **되돌릴 수 있는 작업**입니다.

### ⑥ [Change visibility] 를 누릅니다

작은 창이 뜹니다. 두 개 중에 고릅니다.

```
○ Make public     ← 공개 (지금 이거)
● Make private    ← 비공개  ★ 이걸 고릅니다
```

**`Make private`** 을 고르고 아래 **[I want to make this repository private]** 를 누릅니다.

### ⑦ 확인 문장을 그대로 옮겨 칩니다

깃허브가 「정말 맞느냐」 고 묻습니다. 화면에 나온 글자를 **보이는 그대로**
아래 칸에 칩니다. (창고 이름입니다. 길어도 복사해서 붙여넣으면 됩니다)

다 치면 빨간 버튼이 눌리게 바뀝니다. 누르면 **끝났습니다.**

---

## 2. 잘 됐는지 확인하는 법

창고 이름 **바로 옆**을 보세요.

```
바뀌기 전    이름  [Public]     ← 회색 딱지
바뀐 뒤      이름  [Private]    ← 회색 딱지 · 자물쇠 그림
```

**[Private]** 이라고 적혀 있으면 성공입니다.

---

## 3. 바꾼 다음에 달라지는 것

### 사장님 (거의 없습니다)

| | 전 | 후 |
|---|---|---|
| 창고 보기 | 됨 | 됨 |
| 요금 | 무료 | **무료 그대로** |
| 지금까지 한 작업 | 그대로 | **그대로** |

### 회사 PC / 다른 컴퓨터에서 받을 때 (한 번만)

전에는 그냥 받아졌지만, 이제 **「너 누구냐」 고 한 번 묻습니다.**
로그인 창이 뜨면 깃허브 아이디로 로그인하시면 됩니다.
**한 번만 하면 그 컴퓨터는 다음부터 안 묻습니다.**

> 혹시 비밀번호를 넣어도 안 될 때가 있습니다. 깃허브가 몇 년 전부터
> 비밀번호 대신 **「토큰」** 이라는 걸 쓰라고 바꿨기 때문입니다.
> 그때는 저에게 「토큰 만드는 법 알려줘」 라고 말씀해 주세요. 같이 하겠습니다.

## 4. 비공개로 바꾼 **다음에** 하실 일

이 순서가 중요합니다. **반드시 비공개로 바꾼 뒤에** 하세요.

### ① 오락이 마스터 이미지 3장 넣기

```
내 문서 › 블로그작업 › orak-shortform-studio › assets › master
```

이 폴더에 오락이 그림 3장을 넣습니다.
(폴더 안에 `여기에_넣어주세요.txt` 라는 안내문이 들어 있습니다)

### ② 저에게 말씀해 주세요

「비공개로 바꿨어, 마스터 이미지 넣었어」 라고 하시면
제가 이미지를 막아두던 설정 두 줄을 지우겠습니다.

지금 막고 있는 곳은 저장소 맨 위 `.gitignore` 파일의 43·44번째 줄입니다.
(브랜치는 `orak-shortform-studio` 입니다)

```
orak-shortform-studio/assets/master/*.png
orak-shortform-studio/assets/master/*.jpg
```

> 지금은 실수로 공개 창고에 그림이 올라가지 않게 **일부러 막아 뒀습니다.**
> 비공개가 되기 전에 풀면 그림이 인터넷에 그대로 올라갑니다.

## 5. 자주 나오는 걱정

**「잘못 눌러서 없어지면 어떡하죠?」**
안 없어집니다. 이 작업은 「남이 볼 수 있냐 없냐」 만 바꿉니다.
파일은 하나도 안 건드립니다. 언제든 다시 공개로 되돌릴 수도 있습니다.

**「돈이 나가나요?」**
안 나갑니다. 개인 계정은 비공개 창고도 무료입니다.

**「[Settings] 가 안 보여요」**
그 창고의 **주인 계정으로 로그인**했는지 확인해 주세요.
다른 계정으로 로그인돼 있으면 [Settings] 가 안 보입니다.

**「Danger Zone 이 안 보여요」**
[Settings] 안에서 **맨 아래까지** 내려야 나옵니다. 페이지가 꽤 깁니다.

**「영어라 뭐가 뭔지 모르겠어요」**
화면을 사진 찍어서 저에게 보내주세요. 어디를 눌러야 하는지 짚어 드리겠습니다.

---

## 6. 한 장 요약

```
github.com 로그인
 → 창고 열기
 → 위쪽 [Settings]
 → 맨 아래 빨간 상자 (Danger Zone)
 → Change repository visibility → [Change visibility]
 → Make private 고르기
 → 창고 이름 그대로 옮겨 치기
 → 끝

확인: 창고 이름 옆에 [Private] · 자물쇠

그 다음: assets\master\ 에 오락이 그림 3장 넣고 저에게 알려주기
```
