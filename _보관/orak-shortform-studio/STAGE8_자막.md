## 2. 광고 표시는 아무도 끌 수 없습니다 (§5)

대가성 체크를 켜면 **자동으로** 세 번 들어갑니다.

```
 0.0~ 3.0초   유료광고 포함      ← 첫 장면 전체
10.5~12.5초   유료광고 포함      ← 절반 지점 2초
17.0~23.0초   유료광고 포함      ← 마지막 장면 전체
```

공정위 추천·보증 심사지침이 「시작과 끝에 넣고, 일부만 보는 사람도 알아볼 수
있게 반복 표시」 를 요구합니다.

**끄는 스위치가 없습니다.** 자막을 만드는 함수가 대가성 여부를 **키워드 필수 인자**로
받아서, 빼고 부르면 그 자리에서 오류가 납니다. 시험이 이걸 확인합니다.

본문과 구분되게 **위치(18% vs 64%) · 크기(58 vs 72) · 띠 진하기(0.72 vs 0.45)** 를
모두 다르게 했습니다. 읽히지 않으면 표시하지 않은 것과 같기 때문입니다.

## 3. 눈으로 보고 고친 것 — 이게 이번 단계의 핵심입니다

자막은 **구워서 보지 않으면** 맞는지 알 수 없습니다. 세 번 렌더해서 고쳤습니다.

### ① 배경 띠 여백이 설정 파일을 무시하고 있었습니다

`subtitle_style.json` 에 좌우 48 · 위아래 18 로 적혀 있는데 코드가 **6px 로
하드코딩**돼 있었습니다. 설정 파일을 만들어 두고 안 읽고 있었던 것입니다.

### ② 여백을 키우니 진짜 문제가 드러났습니다

ASS 의 「불투명 상자」 는 **줄마다 따로** 그려집니다. 두 줄 자막에서
상자 두 개가 계단처럼 어긋나 보입니다. 여백을 키울수록 심해집니다.

→ **띠를 직접 그리도록 바꿨습니다.** 글자 크기를 재서(글꼴 파일이 있으면 실측,
없으면 어림) 네모 하나를 글자 뒤에 깝니다. 이제 한 덩어리입니다.

시험이 이걸 지킵니다 — 스타일 줄에 「불투명 상자」 가 다시 나타나면 실패합니다.

### ③ 알아둘 것 — ASS 색은 거꾸로입니다

`&HAABBGGRR` 로 **파랑·초록·빨강** 순서이고, 알파는 **00 이 불투명**입니다.
CSS 와 정반대라 실수하기 쉬워서 함수 하나에 모으고 시험을 붙였습니다.

```
#FF0000 (빨강) → &H000000FF
#0000FF (파랑) → &H00FF0000
```

## 5. 아직 남은 것

**글꼴이 없습니다.** `assets/fonts/` 가 비어 있습니다.
시험은 시스템 글꼴로 돌렸지만, **배포본에는 Noto Sans KR 을 넣어야 합니다** (§7).

```
받는 곳 : fonts.google.com/noto/specimen/Noto+Sans+KR
넣을 곳 : assets/fonts/NotoSansKR-Bold.ttf
```

이 글꼴은 OFL 라이선스라 프로그램에 함께 넣어 배포해도 됩니다.
**맑은 고딕은 안 됩니다** — 윈도우에 있지만 재배포 권리가 없습니다.

굽는 함수가 글꼴 폴더를 FFmpeg 에 알려주므로, 담당자 PC 에 그 글꼴이
설치돼 있지 않아도 같은 모양으로 나옵니다.
