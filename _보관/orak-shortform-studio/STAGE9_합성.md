## 3. 한 번에 굽습니다

§8 이 정한 순서는 **장면 이어붙이기 → 음성 → BGM → 자막** 입니다.
단계마다 따로 인코딩하면 그때마다 화질이 떨어지는데, 인스타그램이 올릴 때
또 한 번 다시 만듭니다. **두 번 손해 볼 이유가 없어서 한 판에 처리합니다.**

대신 필터를 이름 붙인 조각(`_video_chain` · `_voice_chain` · `_bgm_chain` ·
`_subtitle_chain`)으로 나눠 두어서, 잘못되면 **어디가** 잘못됐는지 볼 수 있습니다.

붙이기 전에 장면마다 규격을 맞춥니다 — `scale` → `crop` → `fps` → `setsar=1`.
공급자마다 크기·프레임률·화소비가 달라서, 그냥 붙이면 실패하거나 화면이 튑니다.

## 5. 소리 — 여기서 결함 두 개를 찾았습니다

처음 만든 영상은 배경음악이 **사실상 안 들렸습니다.** 단계마다 재 보며 원인을
둘 찾았고, 둘 다 고쳤습니다.

### ① `amix` 는 기본값이 **나누기** 입니다

```
── amix 기본값 vs normalize=0 ──
  기본값(나눔)       말소리 -17.9 → -23.3 LUFS
  normalize=0(더함)  말소리 -17.9 → -17.9 LUFS
```

`amix` 는 `normalize=1` 이 기본이라 **입력 개수로 나눕니다.** 말소리와 BGM 을
섞으면 둘 다 6dB 씩 작아집니다. BGM 은 -18dB 가 아니라 -24dB 로 깔리고,
말소리까지 먹먹해집니다. `normalize=0` 으로 바꿔 더하게 하고, 넘칠 수 있으니
`alimiter` 로 눌렀습니다.

### ② 「-18dB」 는 **파일을 줄이라**는 뜻이 아니었습니다

§8 은 「voice 대비 -18dB」 라고 했습니다. 그런데 원래 코드는 음원 파일에
그냥 `volume=-18dB` 를 걸었습니다. **넣는 음원마다 원래 크기가 다릅니다.**
조용한 mp3 를 넣으면 안 들리고, 시끄러운 mp3 를 넣으면 말소리를 덮습니다.
담당자가 직접 넣는 음원이라 더 그렇습니다 (§8 — 음원은 동봉하지 않습니다).

그래서 **먼저 재고 맞춥니다.**

```
말소리 목표   -16 LUFS
BGM  목표     -34 LUFS   (= -16 - 18)

넣은 음원                 음원 자체    → 완성본
 아주 큰 음원  (-6dB)     -28.6 LUFS  → -34.0 LUFS
 보통 음원    (-18dB)     -40.6 LUFS  → -34.0 LUFS
 아주 작은 음원 (-30dB)    -52.6 LUFS  → -34.0 LUFS
                                        ↑ 어느 쪽을 넣어도 같습니다
```

말소리도 같습니다. AI 음성은 파일마다 크기가 들쭉날쭉해서, 그대로 두면
어떤 장면만 안 들립니다. **장면마다** 재서 -16 LUFS 로 맞춥니다.

```
일부러 장면마다 크기를 다르게 넣고, 완성본에서 그 구간만 잘라 재 봤습니다.

 장면   넣은 말소리    올린 폭    완성본에서 잰 값
  1     -25.0 LUFS    +9.0dB        -16.0
  2     -41.9         +24.0 (한계)  -17.9
  3     -30.9         +14.9         -16.0
  4     -51.8         +24.0 (한계)  -27.8
  5     -35.8         +19.8         -16.0
```

한없이 키우지는 않습니다. **24dB 가 한계**입니다 — 그 이상 올리면 잡음까지
같이 커집니다. 위 표의 장면 2·4 가 한계에 걸린 경우인데, **일부러 넣은 극단값**
입니다. 실제 AI 음성은 보통 -20 LUFS 안팎이라 한계에 닿지 않습니다.
사실상 무음인 파일(-70 LUFS 아래)은 아예 건드리지 않습니다.

### 왜 최대값이 아니라 LUFS 인가

FFmpeg 는 모노를 스테레오로 펼칠 때 좌우로 나눠 담아 **최대값이 3dB 내려갑니다.**

```
모노 원본        최대 -18.5dB   ·  -22.4 LUFS
스테레오로 펼침   최대 -21.5dB   ·  -22.4 LUFS   ← 최대값만 바뀝니다
```

최대값으로 맞추면 모노 파일만 3dB 작게 깔리는데, **AI 음성은 거의 다 모노입니다.**
LUFS 는 좌우 에너지를 합쳐 보므로 흔들리지 않습니다. 시험으로 못 박았습니다.
