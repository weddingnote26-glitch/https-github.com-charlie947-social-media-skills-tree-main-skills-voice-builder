# 배포본 만드는 법

**읽는 사람**: 사장님 (개발 몰라도 됩니다)
**하는 곳**: **윈도우 PC** — 리눅스·맥에서는 못 만듭니다
**걸리는 시간**: 처음 30분, 다음부터는 5분

---

## 왜 윈도우에서만 되나

만드는 프로그램(PyInstaller)은 **자기가 돌아가는 운영체제용 파일만** 만듭니다.
리눅스에서 만들면 리눅스용이 나오고, 담당자 PC(윈도우)에서는 안 켜집니다.
설치파일 만드는 프로그램(Inno Setup)도 윈도우 전용입니다.

## 처음 한 번만 하는 것 (30분)

python.org 에서 받아 깝니다. **깔 때 「Add python.exe to PATH」 를 꼭 체크**하세요.

```powershell
cd $HOME\Documents
```

### ③ 가상환경과 꾸러미

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
pip install pyinstaller
```

> `.\.venv\Scripts\Activate.ps1` 에서 「스크립트를 실행할 수 없습니다」 가 나오면
> PowerShell 을 관리자로 열고 아래를 한 번만 실행하세요.
> `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`

### ④ FFmpeg 넣기 ★ 꼭 해야 합니다

영상을 실제로 만드는 도구입니다. **저작권 때문에 저장소에 못 넣습니다.**

1. https://www.gyan.dev/ffmpeg/builds/ 에서 **release essentials** 를 받습니다
2. 압축을 풉니다
3. 안에 있는 `bin\ffmpeg.exe` 를 **이 폴더의 `ffmpeg\`** 안에 넣습니다
4. 같이 들어 있는 `LICENSE` 파일도 `ffmpeg\` 안에 넣습니다

```
orak-shortform-studio\
  └ ffmpeg\
      ├ ffmpeg.exe      ← 이게 있어야 합니다
      └ LICENSE
```

**안 넣으면 만들기가 멈춥니다.** 일부러 그렇게 했습니다 — 없는 채로 만들면
담당자 PC 에서 영상이 안 만들어지는데, 그때는 이미 늦습니다.

### ⑤ 자막 글꼴 넣기

fonts.google.com/noto/specimen/Noto+Sans+KR 에서 받아
`assets\fonts\NotoSansKR-Bold.ttf` 로 넣습니다. (OFL 이라 재배포해도 됩니다)

없어도 만들어지지만 자막이 담당자 PC 글꼴로 대체됩니다.

### ⑥ 오락이 마스터 이미지 3장

`assets\master\` 에 넣습니다.
**저장소를 비공개로 바꾼 뒤에** 넣으세요 (`저장소_비공개로_바꾸기.md` 참고).

없어도 만들어지지만 오락이가 나오는 장면을 못 만듭니다.

### ⑦ Inno Setup

jrsoftware.org/isdl.php 에서 받아 깝니다. 설치파일(.exe) 을 만드는 도구입니다.

없어도 괜찮습니다 — `dist\오락숏폼스튜디오\` 폴더를 통째로 복사해도 돌아갑니다.
다만 담당자에게 「폴더 복사하세요」 보다 「이거 두 번 눌러 깔으세요」 가 쉽습니다.

## 만들 때마다 하는 것 (5분)

PowerShell 을 열고:

```powershell
cd $HOME\Documents\블로그작업\orak-shortform-studio
.\빌드.ps1
```

이것만 하면 됩니다. 알아서 이 순서로 갑니다.

```
1. 넣어야 할 것이 다 있는지 확인      ← FFmpeg 없으면 여기서 멈춤
2. 시험 전부 돌리기                  ← 하나라도 실패하면 여기서 멈춤
3. PyInstaller 로 폴더 만들기
4. 만든 것이 진짜 켜지는지 12초 확인   ← 켜자마자 꺼지면 여기서 멈춤
5. 비밀 파일이 섞였는지 확인          ← 섞였으면 여기서 멈춤
6. Inno Setup 으로 설치파일 만들기
```

**중간에 멈추면 빨간 글씨로 무엇이 문제인지 알려줍니다.**

다 되면 여기 나옵니다.

```
설치파일_출력\오락숏폼스튜디오_설치_1.0.0.exe
```

## 담당자에게 주는 법

위 `.exe` 파일 하나만 주면 됩니다. 담당자는 두 번 눌러서 깝니다.

- **관리자 비밀번호를 안 물어봅니다.** 회사 계정이라 모를 수 있어서 그렇게 했습니다.
- 바탕화면 아이콘이 생깁니다.
- **64비트 윈도우만 됩니다.** 요즘 PC 는 다 64비트입니다.

## 자주 나오는 일

**「Windows에서 PC를 보호했습니다」 파란 창이 뜹니다**
서명을 안 산 프로그램이라 그렇습니다. **[추가 정보] → [실행]** 을 누르면 됩니다.
담당자에게 미리 알려주세요. 서명(코드 사이닝 인증서)은 연 20~40만원쯤 합니다.

**백신이 지웠습니다**
드물게 그럽니다. 압축 도구(UPX)를 **일부러 안 썼는데**, 그게 오탐의 가장 큰 원인이라
그렇습니다. 그래도 걸리면 백신에서 예외로 등록해 주세요.

**설치파일이 300MB 가까이 됩니다**
정상입니다. 안에 이만큼 들어 있습니다.

```
화면 그리는 것 (Qt)   약 119MB
FFmpeg               약  77MB
그 밖                 약  70MB
```

담당자 PC 에 파이썬을 따로 안 깔아도 되는 대가입니다.

**만들 때마다 지워도 되나요**
`dist\` `build\` `설치파일_출력\` 은 만들 때마다 새로 나오는 것이라 지워도 됩니다.
**`내 문서\오락 숏폼 스튜디오\` 는 절대 지우지 마세요** — 담당자가 만든 영상이 있습니다.

## 프로그램을 지울 때

담당자가 「프로그램 추가/제거」 에서 지워도
**만든 영상과 설정은 그대로 남습니다.**

```
내 문서 \ 오락 숏폼 스튜디오 \     ← 지우기가 건드리지 않습니다
```

지우고 나면 그렇다고 창을 띄워 알려줍니다.
