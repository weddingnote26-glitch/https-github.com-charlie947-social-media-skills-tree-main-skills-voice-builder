## 1. 먼저 정직하게 — 여기서는 EXE 를 못 만듭니다

**저는 리눅스에서 돌고 있습니다.** PyInstaller 는 자기가 도는 운영체제용만
만들고, Inno Setup 은 윈도우 전용입니다. 그래서 **완성된 윈도우 설치파일은
사장님 윈도우 PC 에서 `빌드.ps1` 을 돌려야 나옵니다.**

그렇다고 「설정만 써 놓고 끝」 은 아닙니다. 여기서 **진짜로 만들어 봤습니다** —
리눅스판으로요. 그러면 윈도우에서만 다른 부분(exe 확장자·서명·설치창)을 빼고
**나머지가 다 맞는지**는 확인됩니다.

### 여기서 실제로 확인한 것

```
PyInstaller 로 진짜 만들었습니다        268MB · 성공
얼린 프로그램을 진짜 켰습니다            12초 동안 안 죽음
  → 자료 폴더를 스스로 만듦             ~/Documents/오락 숏폼 스튜디오/
     Projects · Settings · Assets · Logs · Cache · Exports · Temp
얼린 상태에서 자산을 찾는지              character_profile.json  9,094바이트 ✅
                                       pricing.json           4,581바이트 ✅
                                       subtitle_style.json    3,415바이트 ✅
얼린 상태에서 FFmpeg 을 찾는지           _internal/ffmpeg/ffmpeg ✅
  → **동봉본을 먼저 찾았습니다.** PATH 것도 개발용도 아닙니다
  → zoompan · subtitles 필터 둘 다 있음
배포본에 비밀이 섞였나                   없음 (sqlite3 · credentials · .env · 로그)
소스 코드가 그대로 들어갔나              없음 (전부 묶임)
문서·시험이 들어갔나                    없음
```

### 윈도우에서만 확인할 수 있는 것

| 무엇 | 왜 |
|---|---|
| `.exe` 가 진짜 뜨는지 | 리눅스판은 윈도우에서 안 돕니다 |
| 열쇠 금고(DPAPI) | 윈도우 전용입니다 |
| Inno Setup 설치창 | 윈도우 전용 도구입니다 |
| `빌드.ps1` 문법 | 이 컨테이너에 PowerShell 이 없습니다 (괄호 짝만 맞춰 봤습니다) |
| 백신 반응 | 실제 윈도우에서만 압니다 |

## 3. 한 폴더 방식입니다 (한 파일 아님)

`.exe` 한 개로 묶으면 **켤 때마다 임시 폴더에 268MB 를 풀어놓느라
처음 뜨는 데 10초 넘게 걸립니다.** 담당자가 「고장났나?」 하고 두 번 세 번
누르게 됩니다.

설치파일이 어차피 폴더를 만들어 주므로 한 폴더가 낫습니다.

---

## 4. 뺀 것과 그 이유

```
imageio-ffmpeg     배포본은 **공식 FFmpeg** 를 씁니다 (§8).
                   넣으면 ffmpeg 이 두 개가 되고 라이선스도 애매해집니다.
anthropic          기본 대본 공급자가 OpenAI 라서 뺐습니다.
                   코드는 그대로 두었고, 고르면 「안 들어 있습니다」 라고 말합니다.
cryptography       HTTPS 는 파이썬에 붙은 ssl 로 충분합니다.
                   requests 가 **선택적으로만** 쓰는 것이라 없어도 됩니다.
                   (없이도 되는지 실제로 막아 놓고 확인했습니다)
안 쓰는 Qt 모듈     WebEngine · 3D · Quick · Multimedia · Charts 등 30개.
                   다 넣으면 설치파일이 세 배가 됩니다.
pytest · numpy 등  담당자 PC 에 필요 없습니다.
```

**필요한 걸 실수로 빼면 담당자 PC 에서 그때 죽습니다.** 그래서
`PySide6` · `PIL` · `requests` · `sqlite3` 가 빼는 목록에 **없는지** 시험합니다.

## 5. 크기

```
화면 그리는 것 (Qt)   119MB
FFmpeg                77MB
Pillow 관련           18MB
그 밖                 54MB
──────────────────────────
합계                 268MB
```

담당자 PC 에 파이썬을 따로 안 깔아도 되는 대가입니다.
설치파일로 압축하면 이보다 작아집니다.

**UPX 압축은 일부러 안 썼습니다.** 크기는 줄지만 **백신이 자주 오탐합니다.**
백신이 지워버리면 담당자는 손쓸 방법이 없습니다.

## 6. 지우기가 담당자 영상을 지우지 않습니다 ★

이게 이 단계에서 제일 중요합니다 (§0-1 4번).

```
프로그램  C:\Users\...\Programs\오락숏폼스튜디오\   ← 지우기가 지웁니다
영상·설정  내 문서\오락 숏폼 스튜디오\              ← **건드리지 않습니다**
```

`설치파일.iss` 에 **`[UninstallDelete]` 절을 일부러 넣지 않았습니다.**
지우고 나면 창을 띄워 알려줍니다.

```
프로그램을 지웠습니다.

만드신 영상과 설정은 그대로 있습니다:
내 문서 \ 오락 숏폼 스튜디오 \

그 폴더는 건드리지 않았습니다.
```

시험이 `[UninstallDelete]` 절이 생기면 잡습니다. 실제로 넣어 보고 확인했습니다.

## 7. 관리자 비밀번호를 묻지 않습니다

담당자는 재택 근무자이고 회사 계정이라 **관리자 비밀번호를 모를 수 있습니다.**
`PrivilegesRequired=lowest` 로 내 폴더 안에 깝니다. 물어보지 않습니다.

설치창은 한국어로 뜨고, 언어를 또 물어보지 않습니다.

---

## 8. `빌드.ps1` — 검사 다섯 개

```
.\빌드.ps1
```

이것만 치면 됩니다. 중간에 문제가 있으면 **빨간 글씨로 멈춥니다.**

| 순서 | 검사 | 실패하면 |
|---|---|---|
| 1 | FFmpeg 이 있는가 | 멈춤 — 없이 만들면 담당자 PC 에서 영상이 안 나옵니다 |
| 2 | 시험이 전부 통과하는가 | 멈춤 |
| 3 | exe 가 나왔는가 | 멈춤 |
| 4 | **12초 동안 안 꺼지는가** | 멈춤 — 켜자마자 꺼지는 걸 주면 안 됩니다 |
| 5 | 비밀 파일이 섞였는가 | 멈춤 |

글꼴·마스터 이미지가 없으면 **멈추지 않고 노란 글씨로 알립니다** —
없어도 프로그램은 돌아가되 기능이 줄어들기 때문입니다.
