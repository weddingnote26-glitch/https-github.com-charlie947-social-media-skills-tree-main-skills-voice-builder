# 아이디어 보관함

지시서 §0-5: **기능을 임의로 추가하지 마세요. MVP 완성이 우선입니다.**
좋아 보이는 생각이 떠오르면 코드로 넣지 말고 여기에 적어둡니다.

넣을지 말지는 MVP 18개 판정이 전부 통과한 뒤에 사장님이 정하십니다.

---

## Stage 1 (2026-08-28) 에서 떠오른 것 — **넣지 않았습니다**

| 아이디어 | 왜 안 넣었나 |
|---|---|
| 실패한 Scene 을 다른 렌더 방식으로 자동 대체 (Kling 실패 → Ken Burns) | 담당자가 모르는 사이에 영상 내용이 바뀝니다. 실패는 실패로 보여주고 사람이 정하는 게 맞습니다 |
| Kling 결과를 여러 개 만들어 좋은 것 고르기 | 비용이 그대로 배가 됩니다. 월 한도 5만원에서 감당이 안 됩니다 |
| 지난 영상의 대본·해시태그를 모아 성과 분석 | MVP 범위 밖입니다. 인스타 지표를 가져오려면 자동 수집이 필요한데 §0-4 금지입니다 |
| 자막을 자동으로 줄여 30초에 맞추기 | §8이 "자동으로 잘라내지 마세요" 라고 못박았습니다. 어느 Scene 을 줄일지 보여주기만 합니다 |
| BGM 을 프로그램에 몇 곡 넣어두기 | §8이 동봉을 금지했습니다. 저작권 확인은 사장님 몫입니다 |
| 여러 편을 한꺼번에 만들기 (일괄 제작) | 오작동 한 번에 몇 만원이 나갑니다. 한 편씩 확인하며 만드는 게 안전합니다 |
| 참고 URL 미리보기 (제목만 가져오기) | **§0-4 금지.** 제목만 가져와도 자동 수집입니다. 당근에서 겪은 문제입니다 |
