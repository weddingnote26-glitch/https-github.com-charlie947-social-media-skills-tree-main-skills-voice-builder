| `pyinstaller` | 설치파일 (Stage 11) | 윈도우에서만 |
| SQLite | DB | **파이썬 기본 포함 — 설치 불필요** |

**FFmpeg** — 부품이 아니라 프로그램입니다. §8에 "동봉하라"고 되어 있습니다.

| 방법 | 설명 | 판단 |
|---|---|---|
| `imageio-ffmpeg` (pip) | pip으로 설치되는 ffmpeg 실행파일 | 🟡 **여기서 시험할 때** 이걸 씁니다 (pypi 열려 있음) |
| 공식 빌드 동봉 | ffmpeg.exe + ffprobe.exe 를 설치파일에 넣음 | ✅ **최종 배포는 이것** — §8 요구사항 |

→ 개발 중에는 pip 버전으로 Ken Burns·합성을 시험하고, 설치파일에는 공식 빌드를 넣습니다. 코드는 **ffmpeg 경로를 설정에서 찾아 쓰는 방식**으로 짜서 둘 다 되게 합니다.

## 비용 재계산 — 지시서 숫자 검산

환율 1,380원 기준으로 §11 계산식을 직접 계산해 봤습니다.

| 항목 | 계산 | 원화 |
|---|---|---|
| Kling 2.6 · 1080p | $0.07 × 5초 × 2클립 = $0.70 | **966원** |
| ElevenLabs (400자) | 0.4K × $0.10 = $0.04 | **55원** |
| Gemini 이미지 | ⛔ 장당 요금 미확인 | ? |
| Claude 대본 | 입력·출력 토큰 | 소액 |
| 확인된 요금만 합계 | 966 + 55 | **1,021원** |
| 지시서가 말한 1편 값 | | 약 1,650원 |
| **차이 (= 이미지 + 대본)** | | **약 629원** ← 요금 미확인이라 검증 못 함 |

### ⚠️ 지시서 안에서 숫자 두 개가 서로 안 맞습니다

§1-1은 **"Kling이 전체 비용의 86~90%"** 라고 되어 있고, §11은 **"1편 약 1,650원"** 이라고 되어 있습니다.
**이 둘은 동시에 성립하지 않습니다.**

| 가정 | Kling 비용 | Kling 비중 |
|---|---|---|
| 클립 **2개** (기본값) = 10초 | 966원 | **59%** ← 1,650원 기준 |
| 클립 **3개** (최대값) = 15초 | 1,449원 | **88%** ← 86~90%와 맞음 |

→ **86~90% 는 클립 3개 기준 숫자로 보입니다.** 기본값 2개로 만들면 한 편은 **1,650원보다 쌉니다.**

어느 쪽이든 프로그램 동작에는 문제가 없습니다. 다만:

- 화면에 보여줄 예상 비용은 **`pricing.json` 을 읽어 그때그때 계산**하므로 이 숫자를 코드에 박지 않습니다.
- `직원사용법.md` 의 "1편에 약 ○○원" 도 **`pricing.json` 에서 읽어 표시**합니다 (§14 지시대로 하드코딩 안 함).
- 다만 **Gemini 장당 요금을 모르면 총액을 확정할 수 없습니다.** 「물어볼 것」 1번이 풀려야 정확해집니다.

### 그 밖에 확인한 것

- Kling이 최대 비용 항목인 것은 맞습니다. **클립 수 제한이 비용 관리의 핵심**이라는 §1-1 판단은 타당합니다.
- **Scene 1은 3초만 쓰지만 5초 값을 냅니다.** Kling이 5초·10초만 만들기 때문입니다(3초 요청 시 1201 오류). 2초는 버려지지만 요금은 나갑니다 — 정상이며 피할 방법이 없습니다.
- 월 20편 = 19,300원(2클립) ~ 33,000원(3클립). 한도 기본값 50,000원은 여유가 있습니다.
