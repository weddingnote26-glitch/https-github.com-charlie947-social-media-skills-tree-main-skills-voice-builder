# 오락 두 프로그램 — 분리 규칙

작성 2026-08-28 · **두 Claude Code 세션 모두 이 문서를 맨 앞에 붙여넣으세요**

---

## 왜 이 문서가 필요한가

오락은 지금 **서로 다른 프로그램 두 개**를 만들고 있습니다.

| | A | B |
|---|---|---|
| 이름 | **당근 모임 게시판 콘텐츠 자동생성 프로그램** | **오락 인스타그램 콘텐츠 생성 프로그램** |
| 별칭 | 당근 카드뉴스 도구 | 오락 숏폼 AI 스튜디오 |
| 만드는 것 | 카드 이미지 5장 + 게시글 본문 | 세로 영상 MP4 (Reels·Shorts) |
| 기술 | Python (배포 EXE) | Python + PySide6 (배포 EXE) |
| 쓰는 API | Claude Opus 5 | Claude · Kling · Gemini · ElevenLabs |
| 월 예산 | 30,000원 | 50,000원 |
| 상태 | 콘텐츠 운영 중 · 배포도구 개발 예정 | 신규 개발 (Stage 1) |

**두 프로그램은 코드도, 폴더도, 설정도, API 키도 공유하지 않습니다.**
비슷해 보여도 남남입니다. 한쪽을 고치는 일이 다른 쪽에 영향을 주면 안 됩니다.

## 1. 폴더 배치 — 겹치는 곳이 하나도 없습니다

```
C:\Users\USER\Desktop\
├ 오락_당근_콘텐츠\          [A] 운영 데이터   A 프로그램만 씀
├ 오락_당근_배포도구\        [A] 개발          A 개발자만 씀
└ 오락이 마스터 파일\        [B] 입력 자산     B가 읽기만. 절대 쓰지 않음

내 문서\
├ 블로그작업\
│   └ orak-shortform-studio\  [B] 개발        B 개발자만 씀
└ ORAK_SHORTFORM_STUDIO\      [B] 운영 데이터  B 프로그램만 씀

구글 드라이브 공유 폴더\
└ used_topics.json            [A] 중복 방지 대장   A만 씀

바탕화면 아이콘
├ 오락 당근 콘텐츠 생성기      [A] 실행 바로가기
└ 오락 숏폼 AI 스튜디오        [B] 실행 바로가기
```

**B는 바탕화면에 폴더를 만들지 않습니다.** 바로가기 아이콘만 놓습니다.
그래서 바탕화면에서 두 프로그램이 부딪힐 일이 없습니다.

## 2. 쓰기 권한 — 이 표 밖은 전부 금지

**행위자가 셋입니다. 셋의 허용 범위가 전부 다릅니다.** 이걸 뭉뚱그리면 사고가 납니다.

### A · 당근 카드뉴스

| 누가 | 쓸 수 있는 곳 | 읽기만 | 접근 금지 |
|---|---|---|---|
| **① 개발자**<br>(Claude Code) | `Desktop\오락_당근_배포도구\` | `Desktop\오락_당근_콘텐츠\` **전체** | B의 모든 폴더 |
| **② 배포 프로그램**<br>(담당자가 쓰는 EXE) | `오락_당근_콘텐츠\` 아래 `content\` `output\` `_로그\`<br>구글드라이브 `used_topics.json`<br>`%LOCALAPPDATA%\OrakDaangnTool\` (캐시·설정) | `_규칙\` `_공용\` | B의 모든 폴더 |
| **③ 유지보수 스크립트**<br>(사장님이 직접 실행) | `_공용\` `_규칙\` `_백업\`<br>각 게시판의 `output\` | — | B의 모든 폴더 |

> **③은 이미 존재합니다.** `_공용\양식적용_1회실행.py` 는 `orak_cards.py` 를 고치고,
> `_공용\전체_재생성.py` 는 `output\` 을 다시 만듭니다.
> 이 둘은 **사장님이 손으로 실행**하는 것이며 배포 EXE와 무관합니다.
> **배포 EXE에 이 기능을 넣지 마세요.** 담당자가 실수로 누르면 전체 카드가 다시 그려집니다.

> ①과 ②를 헷갈리지 마세요. 개발자는 운영 폴더를 **읽기만** 합니다.
> 개발 중 시험 출력은 `오락_당근_배포도구\_시험출력\` 에 쓰세요.
> **운영 폴더에 시험 파일을 만들면 담당자가 진짜 콘텐츠와 구분하지 못합니다.**

### B · 오락 숏폼

| 누가 | 쓸 수 있는 곳 | 읽기만 | 접근 금지 |
|---|---|---|---|
| **① 개발자**<br>(Claude Code) | `내 문서\블로그작업\orak-shortform-studio\` | 저장소 안 `assets\master\` | A의 모든 폴더<br>`Desktop\` **전체** |
| **② 배포 프로그램** | `내 문서\ORAK_SHORTFORM_STUDIO\` | 프로그램에 동봉된 마스터 3장 | A의 모든 폴더 |

> **마스터 이미지는 저장소(비공개 전환 후) `assets\master\` 에 두고 EXE에 동봉합니다.**
> 완성된 프로그램은 `Desktop\오락이 마스터 파일\` 을 볼 필요가 없습니다.
> 바탕화면 원본은 사장님 보관용이며, **개발자도 프로그램도 접근하지 않습니다.**

## 3. 절대 금지 — 양쪽 공통

1. **상대 프로그램의 폴더를 읽지도, 쓰지도, 지우지도 마세요.**
   참고할 코드가 있어도 **복사하지 말고 새로 쓰세요.** 공유하면 한쪽 수정이 다른 쪽을 깨뜨립니다.

2. **`오락_*` 같은 와일드카드로 폴더를 찾지 마세요.**
   두 프로그램 폴더가 전부 `오락_` 으로 시작합니다. `오락_당근_콘텐츠` 를 지우려다 `오락_당근_배포도구` 까지 잡힙니다.
   **경로는 항상 전체 경로를 문자 그대로** 쓰세요.

3. **파일을 지우는 코드를 쓰지 마세요.**
   `rm -rf`, `shutil.rmtree`, `os.remove`, `robocopy /MIR`, `git clean -fdx`, `git reset --hard` 전부 금지입니다.
   정리가 필요하면 지우지 말고 `_보관\` 폴더로 **옮기고** 사용자에게 알리세요.

4. **설정 파일을 공유하지 마세요.**
   두 프로그램은 각자 `config.json` 을 가집니다. 경로가 다르고 내용도 다릅니다.
   한쪽 설정을 다른 쪽이 읽으면 안 됩니다.

5. **API 키를 공유하지 마세요.**
   A는 카드뉴스용 Claude 키 하나. B는 Claude·Kling·Gemini·ElevenLabs 키 넷.
   **A와 B의 Claude 키도 서로 다른 키입니다.** 비용을 나눠서 봐야 합니다.

6. **폰트·FFmpeg 같은 공용 부품도 각자 동봉하세요.**
   한 곳에 두고 둘이 가리키면 한쪽을 업그레이드할 때 다른 쪽이 깨집니다.
   용량이 조금 늘어도 각자 갖는 편이 낫습니다.

7. **파이썬 환경을 공유하지 마세요.**
   각자 `venv` 를 따로 만드세요. 한쪽에서 패키지를 올리면 다른 쪽이 깨집니다.

8. **같은 저장소에 넣지 마세요.**
   A는 바탕화면 폴더, B는 `블로그작업` 저장소입니다. 지금 상태가 맞습니다. 합치지 마세요.

## 3-1. 중복 방지 대장 — 정본이 어디인지 먼저 정리하세요

지금 대장이 **두 곳에 있을 예정**입니다. 그대로 두면 갈라집니다.

```
지금        Desktop\오락_당근_콘텐츠\_공용\used_topics.json   ← 운영 중 (26건)
앞으로      구글 드라이브 공유 폴더\used_topics.json          ← 정본이 될 곳
```

**최초 1회, 사장님이 손으로 하세요. 프로그램이 자동으로 옮기게 하지 마세요.**

```
1. _공용\used_topics.json 을 구글드라이브 공유 폴더로 복사
2. 원본은 지우지 말고 이름만 바꿔 보관
     _공용\used_topics_구버전_20260828.json
3. 그 뒤로 프로그램은 구글드라이브만 봅니다
```

- 배포 프로그램은 **로컬 `_공용\` 의 대장을 읽지도 쓰지도 않습니다.**
- 드라이브를 못 읽었을 때 쓰는 **로컬 캐시는 `%LOCALAPPDATA%\OrakDaangnTool\used_topics_cache.json`** 입니다.
  운영 폴더에 캐시를 만들지 마세요.

## 4. 이름이 겹치는 것들 — 헷갈리지 마세요

두 프로그램에 **비슷한 이름의 다른 파일**이 있습니다. 서로 바꿔 쓰면 안 됩니다.

| 개념 | A 당근 카드뉴스 | B 오락 숏폼 |
|---|---|---|
| 디자인 값 | `_공용\theme.json` | `assets\subtitle_style.json` |
| 캐릭터 설정 | 없음 | `assets\character_profile.json` |
| 요금표 | `config.json` 안에 | `assets\pricing.json` |
| 중복 방지 | `_공용\used_topics.json` | 없음 |
| 렌더 엔진 | `_공용\orak_cards.py` (PIL) | `providers\video_kenburns.py` (FFmpeg) |
| 결과 미리보기 | `preview.html` | `final\*.mp4` |
| 규칙 문서 | `_규칙\본문_작성규칙.md` | 지시서 §6·§7 |

**A의 `theme.json` 과 B의 `subtitle_style.json` 은 완전히 다른 파일입니다.**
한쪽 값을 다른 쪽에 복사하지 마세요.

## 5. 세션을 시작할 때마다 확인하세요

작업을 시작하기 전에 **매번** 아래를 스스로 확인하고, 답을 한 줄로 적고 시작하세요.

```
□ 나는 지금 A(당근 카드뉴스) 인가, B(오락 숏폼) 인가?
□ 내가 쓸 수 있는 폴더는 어디인가?  (2번 표에서 확인)
□ 이번 작업에서 상대 프로그램 폴더를 건드릴 일이 있는가?  → 있으면 멈추고 물어보기
□ 파일을 지우는 코드가 들어가는가?  → 있으면 멈추고 물어보기
```

예시:

> 저는 **B(오락 숏폼)** 세션입니다.
> 쓰기: `내 문서\블로그작업\orak-shortform-studio\` 만.
> 읽기: 저장소 안 `assets\master\` 만.
> A 폴더는 건드리지 않습니다. 삭제 코드 없습니다.
